# 出来事から、自分のジャンルへの持っていき方

## 大原則

1. **出来事はフックと共感のための素材**。出来事そのものを最後まで語らない。出来事から発信軸のテーマへ橋を架ける
2. **橋は1本だけ**。1つの出来事から複数の教訓を引き出さない。こじつけ感が出るくらいなら、訴求を弱めて共感で終わらせるほうがいい（毎回売るストーリーは見られなくなる）
3. **こじつけていい。**出来事と伝えたいことがきれいにつながることは、まず起きない。つながって見える人は、つなげているだけ
4. ただし**いきなり結論や問いかけから入らない**。見ている人が置いていかれる

## 持っていき方のパターン（★これで固定しない・毎回変える）

### パターン1：様子を描く → 共感を呼ぶ → 問いかける
いちばん基本。
1. その場の様子を見えるように描く
2. 「こういう経験ある人いると思うんだけど」と共感を呼ぶ ← **これは例のひとつ。毎回この言い方をしない**
3. 問いかける／着地する

### パターン2：損から入る → 原因 → 基準を渡す
「◯◯を3日でだめにした」→ なぜそうなったか → 「実は△△で決まる」

### パターン3：思い込みを出す → 裏切る → 一般化
「◯◯だと思ってたけど…」→ 実は違った → 「これは全員に言えることで」

### パターン4：他人のコンテンツから広げる
動画・本・ニュース・DMのスクショ → 自分の解釈 → 発信軸へ

### パターン5：経緯を並べる（⋮）
出来事 ⋮ そのとき考えたこと ⋮ やったこと ⋮ 変わったこと → 「あの時◯◯した自分を褒めたい」

### パターン6：2軸で並べる
「◯◯する人 👉 こうなる」「しない人 👉 こうなる」→ 「私は前者でありたい」

⚠️ **前回と同じパターンを続けて使わない。**`neta_cho.md` の使用ログを見て選ぶ。

## ★橋の1行（これが無いと自分語りで終わる）

自分の話を読者の話に変える1行。着地の直前に入れる。
- 「これは全員に言えることで」
- 「みーんな◯◯。でも自分に自信がないだけ」
- 「昔の私と同じように◯◯な人の」
- 「って事を周りも分かってあげてほしい」

**この1行は毎回言い方を変える。**同じ表現を続けるとテンプレに見える。

## 着地の候補を3つ出す（STEP 4で使う）

ユーザーに「どこに着地したい？」と聞いても答えられない。
出来事 × ゴール × 型 から、**自然につながる着地を3つ作って見せて選んでもらう**。

例）出来事「スタバで隣の人が平日の昼間にPCで作業していた」／発信軸「自己投資・働き方」
- A（共感）「平日の昼間に自由に働いている人を見ると、少しだけ焦る」で終わる
- B（教育）「働く場所を選べるかどうかは、才能じゃなくて過去の選択の延長線上にある」
- C（親近感）「昔の自分なら"いいな"で終わってた。今は自分もあっち側にいるのが不思議」
  → 「あのとき行動した自分を褒めてあげたい」で締める

## 枚数の決め方

**枚数は決めるものではなく計算するもの。**
その出来事から着地まで、何段の階段が要るかを数える。
1枚で完結するなら1枚。5枚必要なら5枚。**3枚と決めたせいで話を薄く引き伸ばすのがいちばん悪い。**

文字量「少なめ」を選んだ人は、1枚の情報量が減るぶん**枚数を増やして**同じ着地に運ぶ。

## 1枚目は必ずフックにする

1枚目の役割は内容を伝えることではなく、**親指を止めること**。
「今日は撮影日にします」のような予定の報告は、そのまま指で送られて終わる。

⚠️ **1枚目は約束。**フックだけ強くして中身が伴わないのを2回やると、次から見てもらえない。

## 最後の1枚

- 自分の話をせずに終わる（ここで語ると質問が来なくなる）
- **相手が投げ返せる球**を投げる（「みんな◯◯どうしてる？」＝1秒で返せる。「人生観を教えて」＝重すぎる）
- 返ってきた答えが、そのまま明日のネタになる
