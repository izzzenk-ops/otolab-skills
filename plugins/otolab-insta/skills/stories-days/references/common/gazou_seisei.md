# ストーリー画像の作り方（文面の承認後にだけ実行する）

⚠️ **文面の承認前に画像を作らない**（作り直しになるだけ）。

## 前提をそろえる

1. 承認済みの文面（文面.md）
2. 見た目：ユーザーのデザインの参考があれば `参考_デザイン/<名前>/デザインプロファイル.md`。無ければ `design_kijun.md` の既定（文字＝段落＋札・写真＝手元のアップ）
3. 写真：`shashin.md` の優先順で決める（指定の画像 → 指定フォルダ → 写真素材/ → AI → 一色）
4. 見せ方の引き出し：`hyogen_hikidashi.md`

## 手順

1. **枚ごとに見せ方を割り振る**（`hyogen_hikidashi.md` の配分を見て、全部同じにならないように）
2. 写真が足りない枚があり、AIで作る場合は、作る枚と内容を一覧にして**「この◯枚をAIで作ります」と伝えてから**作る
   ```bash
   python3 <スキル>/references/common/tools/gen_image.py <作成済み/日付_テーマ>/photos/03.png --kind tetemoto --scene "英語で場面"
   ```
3. `作成済み/<日付_テーマ>/frames.js` を書く（書き方は下）
4. 書き出す
   ```bash
   python3 <スキル>/references/common/tools/render.py <作成済み/日付_テーマ>/frames.js
   ```
   → `png/01.png …` と `png/一覧.png` ができる。スタンプの位置を確かめたいときは `--draft` を付けて別フォルダに出す
5. **全部の枚を見る**（Readで `png/一覧.png` を開き、気になる枚は1枚ずつ開く）。見るのはこの5つ：
   - 文字が途中で改行していないか（「言ってたんだよ／ね。」）
   - 文字が写真の主役（手元・料理・人）にかかっていないか
   - 明るい部分で文字が読みにくくなっていないか（→ `dim` を上げる・札に変える）
   - 上約250px・下約340pxに文字がかかっていないか
   - 配分（見出し3割以下・貼り込み3〜5割・左寄せ2〜3割）から大きく外れていないか
   書き出しの最後に「⚠️ 直したほうがいいところ」（文字のはみ出し・表示できない写真）が出たら、必ず直してから納品する
6. 崩れていたら frames.js を直して書き出し直す
7. 納品：png フォルダを開く（Mac は `open <png>`、Windows は `explorer <png>`）
8. アフィリエイト・企業案件なら、「#PR」は画像に入れない。**投稿するときに、本人がインスタの画面で右上に「#PR」を入れる**（文面.mdに「何枚目に入れるか」を書いて伝える）
9. 文面.md に、画像にしなかったもの（質問スタンプ・アンケート・リンク・カウントダウン・メンション・PR表記の場所）を**「何枚目の、どこに置くか」**として書いてあることを伝える
10. AIで作った写真を使った枚があれば、「投稿のとき『AI情報』のラベルを付けておくと安心です（静止画は義務ではありません）」とひと言そえる

## frames.js の書き方

```js
// 色とフォント（ユーザーの世界観に合わせる。省略すると既定）
window.THEME = {accent:'#e8834a', ink:'#4a3428', light:'#f3ece0'};

window.F = [
  // 写真の上に段落＋白い丸札
  {photo:'photos/01.png', top:520, dim:.25, b:[
    ['h','お待たせしました🙏'],
    ['p','10日くらい前から<br>ちょこちょこ話してた<br>「平日の買い物が減った話」'],
    ['w',['やっと話せます']],
    ['s','（長くなるから、ゆっくり見てね）'],
  ]},
  // 一色の背景・短い2行・アクセント色の札
  {solid:'#f3ece0', light:1, top:760, fs:50, b:[
    ['p','子どもの朝ごはん、間に合わないやつ😱'],
    ['o',['起きた瞬間に血の気が引いた']],
  ]},
  // 左寄せ・白い角札を積む・スタンプは指示だけ
  {photo:'photos/03.jpg', top:300, dim:.25, left:1, sticker:'質問スタンプ「みんなはどうしてる？」', b:[
    ['ws',['スーパーで15分、','立ち尽くしてた日もあった😶']],
    ['d',['決まってなかっただけなんだけど']],
  ]},
];
```

| 枚の指定 | 意味 |
|---|---|
| `photo` | 写真の場所（frames.js からの相対パス／絶対パス。Windowsの `C:\\…` も可）。jpg・png。HEICはMacなら自動変換。見つからないと書き出しが止まる |
| `solid` | 一色の背景（`photo` の代わり）。明るい色なら `light:1`（文字が `ink` の色になる）、濃い色なら `inkl:1`（文字が `light` の色になる） |
| `dim` | 写真の暗さ 0.12〜0.45 |
| `top` | 文字の始まりの高さ（250〜1100px）。主役にかからない高さにする |
| `fs` | 本文の文字サイズ（既定40px。短い枚は46〜52） |
| `left:1` | 左寄せ |
| `sticker` | 画像には描かない。下書き（--draft）のときだけ点線の目印 |

部品の一覧は `hyogen_hikidashi.md`。

### THEME（色とフォント）で指定できるもの

| 名前 | 意味 | 既定 |
|---|---|---|
| `ink` | 明るい背景のときの文字の色 | こげ茶 |
| `accent` | アクセント色の札（`o`）の色 | オレンジ |
| `marker` | マーカーの色 | ピンク |
| `red` | 赤い丸札（`r`）の色 | 赤 |
| `light` | 濃い一色背景（`inkl:1`）のときの明るい文字の色 | ベージュ |
| `chip` / `chipink` | 白い丸札（`w`）の地の色／文字の色 | 白／黒 |
| `round` | 丸札の角の丸み。**単位つきの文字で**（例 `'14px'`） | `'40px'` |
| `font` | フォント。丸いフォントは `'"Zen Maru Gothic",sans-serif'` か `'"M PLUS Rounded 1c",sans-serif'` | ヒラギノ／Noto Sans JP |

ユーザーの希望（パステル・丸いフォント など）はここで合わせる。

## 動く環境

- Mac・Windows どちらも動く（Google Chrome か Microsoft Edge が入っていればよい。Python は標準ライブラリだけ）
- ★**Windowsでは `python3` を `py` に読み替える**（`python3` と打つとMicrosoft Storeが開くことがある）。Pythonが無ければ python.org から入れる（インストール画面で「Add python.exe to PATH」にチェック）
- 出力先のフォルダ（`~/Documents/Claude/Projects/ストーリーズ作成/`）が無ければ作ってから書き出す
- 文字はMacならヒラギノ、WindowsならNoto Sans JP（ネットにつながっていれば自動で読み込む）か游ゴシック
- AIの背景写真は ChatGPT の有料プランがあるときだけ。無くても最後まで作れる
