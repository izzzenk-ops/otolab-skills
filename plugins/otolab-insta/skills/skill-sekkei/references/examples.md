# 良い設計書と悪い設計書（実例）

登場する人物・お店はすべて架空。Phase 3〜7 で「どこまで具体的に書けばいいか」に迷ったときに読む。

---

## 例1｜人見知りの美容師さんが「投稿のネタ切れを何とかしたい」

### ❌ 悪い設計書（よくある形）

```
## 1. ひとことで言うと
インスタのネタを考えてくれるスキル

## 6. 手順
1. ネタを考える
2. いい感じにまとめて出す

## 7. できたか確かめる方法
いい感じのネタが出ていればOK

## 14. 完成の定義
ネタ切れしなくなること
```

**何がダメか**

- 「ネタを考える」は手順ではない。**何を材料に、何を見て考えるのかが無い**ので、
  毎回ちがう当てずっぽうが出てくる
- 「いい感じ」は確かめられない。**数えられない合格ラインは、無いのと同じ**
- 完成の定義が、スキルではなく人生の目標になっている（判定できない）

### ⭕ 良い設計書（同じ相談から作ったもの）

```
## 1. ひとことで言うと
今週お客さんから実際に聞かれた質問を渡すと、投稿ネタを5本に整理して出してくれるスキル

## 5. お手本・元ネタ
- 参考URL: <伸びている同業アカウントの投稿3本のURL>
- 手元のファイル: 今週のカルテメモ（お客さんに聞かれたことのメモ）
- 無い場合どうするか: メモが無い週は「先週の投稿への質問コメント」で代用する

## 6. 手順
### 手順①: 材料を読む
- やること: 渡されたメモと、参考URL3本の投稿を読む
- 出てくるもの: お客さんの質問リスト
- ここまでできたら次へ進む: 質問が3つ以上ひろえたら

### 手順②: ネタ候補を10本出す
- 出てくるもの: 1行タイトルが10本
- ここまでできたら次へ進む: 10本そろったら（ここで一回見せる）

### 手順③: 5本に絞って中身を書く
- 出てくるもの: 5本ぶんの「タイトル・話す内容3行・締めの一言」

## 7. できたか確かめる方法
| 手順 | 何を見てOKと言うか |
|---|---|
| ① | 質問が3つ以上ひろえている |
| ② | 10本のタイトルが、全部ちがう質問から来ている（同じ質問の言い換えが無い） |
| ③ | 5本すべてに「話す内容3行」が入っている |
- ここで一回見せて: 手順②のあと

## 14. 完成の定義
5本ぶんの投稿ネタが、そのまま撮影に入れる形（タイトル＋話す内容3行＋締め）で出ている
```

**何が違うか**

- 材料が決まっている（**カルテメモという実物**）ので、当てずっぽうにならない
- 合格ラインが**数えられる**（3つ以上・10本・全部ちがう・3行入っている）
- 手順②のあとで止まるので、方向がズレていたらそこで直せる

## 例2｜町の花屋さんが「お客さんの声をまとめたい」

### ❌ 悪い書き方（起動の言葉）

```
## 3. 起動の言葉
「まとめて」
```

**何がダメか**

- 短すぎて、ほかの作業でも反応してしまう。逆に、少し違う言い方をすると**呼んでも出てこない**
- 既存スキルと突き合わせていない

### ⭕ 良い書き方

```
## 3. 起動の言葉
- 「お客さんの声まとめて」
- 「口コミまとめて」
- 「アンケートの結果まとめて」
- 「今月の感想を整理して」
- 「レビューまとめといて」
- 「お客さんの声の続き」（中断からの再開用）
- 棲み分け: ※投稿の文章を書くのは別スキル。これは声を集めて整理するところまで
```

## 例3｜「まだ決まっていないこと」の書き方

### ❌ 空のまま出す

```
## 12. まだ決まっていないこと
なし
```

ヒアリングの1回目で本当に全部決まることはまずない。「なし」と書くと、
受け取ったClaudeが**勝手に決めて進む**。

### ⭕ 正直に残す

```
| # | 決まっていないこと | どう確かめるか | 状態 |
|---|---|---|---|
| 1 | お客さんの声を毎回どこから持ってくるか（DMか、紙のアンケートか） | 本人に聞く | 未 |
| 2 | 名前を出していいのか（イニシャルにするか） | 本人に聞く。決まるまでは全部イニシャルにする | 未 |
```

決められないものに**仮の扱い**を書いておくと、そこで止まらずに進める。

## 迷ったときの物差し

| 迷い | どうする |
|---|---|
| 手順が細かすぎる気がする | 3〜7手順に収める。8個を超えたらスキルを2本に分ける |
| 合格ラインが思いつかない | 「数えられるか？」で判定する。数えられないなら書き直す |
| お手本が無い | 無いまま進めてよいが、**「なんとなくそれっぽいもの」が出る**と正直に伝える |
| 相手が「おまかせで」と言う | こちらが決めて、**決めた内容を3行で報告する**。黙って決めない |
