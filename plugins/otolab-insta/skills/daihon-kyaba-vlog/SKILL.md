# daihon-kyaba-vlog｜41歳〔自分のジャンル〕オーナー・1日Vlog台本作成スキル

## このスキルについて
ユーザー（**41歳〔自分のジャンル〕オーナー**）がその日あった出来事を時系列で話す。それを、参考発信者・〔話者名〕（〔参考アカウント〕）ゆずりの **大阪弁・一人称・等身大の「1日Vlog実況ナレーション」文体** に変換して台本化する。

参考スタイルの一次ソース：〔話者名〕の実動画30本（全文校正済み → `references/reference-scripts.md`）。

## 【このスキルの核】ギャップがすべて

このスキルの面白さの正体は、**41歳のおじさん・〔自分のジャンル〕オーナー（けんじ）が、21歳キャバ嬢そのままのギャル口調で1日を語る**という強烈なギャップにある。ここがブレると全部台無しになる。だから：

- **口調・語尾・テンションは一切薄めない。** おじさんだからと落ち着けたり、丁寧にしたりしない。**中身はおじさんの日常、喋り方は21歳キャバ嬢100%。** このミスマッチが笑いを生む。
- **借りるのは「話題」ではなく「喋り方（語尾・言い回し・ノリ）」。** キャバ・同伴・アフターなど参考元の生活ネタは混ぜない。台本の**中身はユーザー（けんじ）が話した実際の出来事だけ**を使う。
- 例：サンプルの色が指定と違って届いた → 「**ほんましんどいぃ〜**」「これ色ちゃうやん、まじ無理なんやけどぉ〜」「**もう無理むり、限界すぎ**」のように、キャバ嬢がこぼす感じの語尾・ノリでそのまま言う。
- 例：新作の撮影がバチッと決まった → 「**まじ最高すぎぃ〜**」「**神やん**」「テンション爆上がり」。
- 例：発送作業が終わらない → 「**やばいやばい、秒でやらな**」「**もう泣きそぉ〜**」。

つまり **「おじさんの出来事」×「キャバ嬢の口調」** を毎行で掛け合わせる。参考台本30本は、その"キャバ嬢の口調"の一次ソースとして使う。

## ワークフロー

### STEP 1：情報収集（時系列で聞く）
ユーザーはその日あったことを時系列で話す。以下を把握する。すでに話してあれば即台本生成に入る。**質問しすぎない。7割あれば生成、残りは日常あるあるで自然に補う。**

- その日の出来事（時系列。起床→準備→仕事/外出→ご飯→帰宅・就寝 など）
- 訪れた場所・食べたもの・やったこと・作ったもの
- 印象的だったこと・感想・小さなオチ
- その日のコンディション（寝すぎ／早起きできた／疲れ／締切に追われ など）
- 締めの向き先（このあとまだ仕事 or もう就寝 など）
- 尺感（短め15〜30秒 / 標準30〜50秒 / 長め60秒前後）
- 自称名がまだ設定されていなければ確認する。

### STEP 2：文体を体に入れてから書く
書く前に、必要なら `references/reference-scripts.md`（実台本30本）に目を通し、リズムと単語選びを掴む。**内容ではなく"言い方"を吸収する。**
後述の「文体の核」「語彙・言い回し」「構成テンプレート」に沿って、大阪弁の口語でそのまま喋っているように書く。丁寧な書き言葉に流れないよう常に語彙リストを参照する。

### STEP 3：出力
「出力形式」に従って、タイトル案＋台本＋使った言い回しを提示する。

## ［最重要］文体の核

1. **一人称・大阪弁**。「〜やねん」「〜やんねんけど」「〜してん」「〜てんけど」「〜やし」「〜くない？」「めっちゃ」「ほんまに」「バリ」。丁寧語にしない。
2. **自分を名前でも呼ぶ**。強調したいときに三人称的に差し込む（例：「けんじも逆立ちやってみたけど全然無理やった」「もはやけんじやと思われてない」）。基本は一人称、スパイスとして名前。
3. **冒頭は必ず、このセルフ訂正ギャグの定型**：
   「**21歳キャバ嬢…あっ、違う違うっ、41歳〔自分のジャンル〕オーナー、〔その日の状況〕のVlog〜。**」
   - 前半で思わず「21歳キャバ嬢」と名乗りかけ、「あっ、違う違うっ」で我に返って正しい肩書きに訂正する、という**掴みのギャグ**。ここが毎回の顔。
   - 〔その日の状況〕だけ毎回変える（例：新作撮影する日／サンプル届く日／展示会準備する日）。
   - 「Vlog」は語尾を伸ばして**「Vlog〜」**と表記する（発音は「ぶいろぐ〜」だが、字面は Vlog〜 で統一）。
4. **締めは必ず定型**：「**みんな最後まで見てくれてありがとう。**」（直前に「今日も〜」の一言を置く）
5. **時系列の実況**。今まさに動いている実況＋独り言。「〜行ってきまーす」「〜していくよ」「〜するよー」。
6. **視聴者への問いかけを1〜2回入れる**。「みんなは〜する？」「〜あったら教えて」。コメント誘発の生命線。
7. **等身大の自虐・ダメ人間告白を明るく**。寝すぎた／部屋汚い／ダラダラした／また食べすぎた／締切ギリギリ、を恥じずネタにする。
8. **感情は素直・全力**。「最強に美味しい」「ウキウキ」「幸せ」「最高」「嬉しい」を惜しまない。
9. **オノマトペ・畳語を多用**。ガチガチ／モフモフ／グーたら／ゴロゴロ／パッパッ／ぐっちゃぐちゃ／下げ下げ／ガスガス。
10. **どこかに"ご飯シーン"を入れる**。1日のうち食べ物の実況（食レポ）を1回は挟むと〔話者名〕らしくなる。
11. **一文は短く、テンポよく言い切る**。だらだら説明しない。道具や固有名詞を並べすぎない（例：「照明組んでカメラ1台2台3台とドローンとAI追跡のやつまで用意して」→「めっちゃいっぱいカメラ用意して撮影〜。AIが追っかけてくれるからほんま楽ぅ〜」）。細部より、ノリと語尾を優先する。
12. **固有名詞は"伝わりやすさ"で調整する**。マニアックな固有名詞（車種名など）は一般名詞に落とす（「ラングラー」→「車」）。逆に、それだけだと伝わらない語は分かる言葉を足す（「日本代表戦」→「サッカー日本代表戦」）。視聴者がパッと分かるかで判断。

## ［最重要］ギャル語尾の再現ルール

〔話者名〕の口調のいちばんの肝は、**語尾を伸ばして柔らかくするギャルっぽい喋り方**。台本では **小さいカナ＋伸ばし棒（ー）／波ダッシュ（〜）** で表記して、実際の喋りを字面で再現する。これができないと「ただの大阪弁のおじさん」になってギャップが死ぬ。

### 基本
- 「Vlog」は語尾を伸ばして**「Vlog〜」**と表記する（字面は Vlog〜 で統一）。冒頭は必ずセルフ訂正ギャグの定型「**21歳キャバ嬢…あっ、違う違うっ、41歳〔自分のジャンル〕オーナー、〔その日の状況〕のVlog〜。**」
- **全部の語尾を伸ばさない。** テンションが上がる宣言・実況で伸ばし、内省や淡々とした情報は伸ばさない（全部伸ばすとくどい）。実データでも「宿題みたいで楽しい」「楽しくて時間一瞬」等は伸ばしていない。
- 伸ばす音は、直前の母音に合わせた**小さいカナ**を足して「〜」で締める：

| 直前の母音 | 足す小さいカナ | 例 |
|-----------|--------------|----|
| u（く・す・つ・る・ぐ…「する」「到着」） | **ぅ** | 到着ぅ〜／メモするぅ〜／飛んでいくぅ〜 |
| i（き・し・ち・い…「楽しみ」「可愛い」） | **ぃ** | 楽しみぃ〜／可愛いぃ〜／おもろい〜 |
| o（こ・そ・の・ろ・ょ…「完了」「頑張ろう」） | **ぉ** | 完了ぉ〜／頑張ろぉ〜／激重ぉ〜 |
| e（け・せ・て・ね…「完成」「新鮮」） | **ぇ** | 完成ぇ〜／新鮮ぇ〜 |
| a（か・た・な・ら…「疲れた」「貸した」） | **ぁ** | 疲れたぁ〜／貸したぁ〜／起きれたぁ〜 |

### 定番の語尾形
| 素 | ギャル語尾 |
|----|-----------|
| 〜するよ／していくよ | **〜するよ〜／していくよ〜**（さらに柔らかく「**〜よ〜ん**」も：綺麗にしていくよ〜ん） |
| 〜行きます | **行ってきまーす**（定番。「まー」で伸ばす） |
| 到着／完了／購入／出勤 | **到着ぅ〜／完了ぉ〜／購入ぅ〜／出勤ぅ〜** |
| 楽しみ／可愛い／おもろい | **楽しみぃ〜／可愛いぃ〜／おもろい〜** |
| 頑張ろう／寝よう／しよう | **頑張ろぉ〜／寝よ〜／しよ〜** |
| 疲れた／最悪／すぎる | **疲れたぁ〜／最悪ぅ〜／すぎるぅ〜** |
| ありがとう（締め） | **ありがとぉ〜** |

### 使いどころ（音声分析より）
- 撮影・買い物・楽しい系のテンション高め回は**よく伸ばす**。
- 落ち着いた内省・情報の文は**伸ばさない**。
- 問いかけ（「なんなんやろ〜」「〜くない？」）は軽く伸ばすと可愛い。
- 感情のこぼし（後述）も伸ばす：「ほんましんどいぃ〜」「まじ無理ぃ〜」。

## ［核心］秀逸な言い回し・例えの事例集

参考発信者の単語選び・比喩のセンス。**"言い切り変換"の実例集**として使う。ここに並ぶ表現は、そのまま使えるもの（下線太字）と、「同じ発想でユーザーの出来事を言い切る」ための見本の両方がある。

> **変換のコツ**：出来事をそのまま説明せず、「それって要するに何に似てる？」を一瞬考えて一言で言い切る。お腹→妊婦、疲れ顔→顔が寄ってる、汚部屋→泥棒、際限なく食べる自分→無限の飯袋。この"変換"がセンスの正体。〔自分のジャンル〕オーナーの1日（新作撮影・サンプルチェック・検品・発送・SNS撮影・展示会）にも同じ発想を効かせる。

### ① お腹・食欲の比喩
- **「食べすぎてまた妊婦（なってもうた）」** ― 満腹でぽっこりしたお腹を「妊婦」と言う（鉄板ネタ）
- **「無限の飯袋（や）」** ― 際限なく食べる自分を「飯袋」と自称
- **「油苦手なけんじでもバクバク食べちゃう、無限に食べれそう」**
- **「美味しすぎてマジで止まらん」／「ほっぺた落ちそう」**

### ② その日のコンディション・自虐
- **「頑張って理性保ってる、すごいよな」**（自分で自分を褒める自虐）
- **「記憶のない豚足がテーブルの上にある」**（覚えのない物を"記憶のない○○"と表現）
- **「〜すぎて今にもぶっ倒れそう」／「〜すぎて死にそう・死んでた」**
- **「もはやけんじやと思われてない」**（バズりすぎ・別人扱いの自虐）

### ③ 部屋・生活のだらしなさ
- **「泥棒入ったんかってくらい家汚い」**
- **「部屋の乱れは心の乱れって言うから綺麗にしていくよ」**（ことわざで自分を戒める）
- **「もういい、ぐっちゃぐちゃ」／「グーたら爆睡してた」**
- 「体に優しいもん食べたい」と言いつつ結局冷凍焼きそば、のような**言行不一致のオチ**

### ④ 自分・状態のうまい言い切り
- **「顔が寄ってる」**（疲れ顔）／ **「声ガスガス」**（かれた声）／ **「気分下げ下げ」**
- **「メンタルもギリ保ててる」**
- **「ビビリ散らかしてる」**（＝ビビりまくり。「〜し散らかす」で強調）
- **「寝起き1分で行ってきまーす」**（フットワークの軽さ）

### ⑤ 家族・人のあたたかい描写
- **「妹が自分のお小遣いで買ったチョコくれて優しい」／「珍しく弟が払ってくれて嬉しい」**
- **「足引っ張られてバリ痛いし、行くまで寝させてくれへんらしい。結局連行させられた」**（強引さを"連行"と表現）
- **「これ稼いできなさいとか言われたから、今日もお仕事頑張ろー」**

### ⑥ ちょっとした世の中への一言
- **「ロボットが持ってきててびっくりした。時代ってすごい」**（配膳ロボへの素朴な感想）
- **「毎日書いて偉いって褒めてくれるけど…宿題みたいで楽しい」**
- **「17歳から1年に1回ぐらい引っ越ししてる。荷物の量がだんだんレベルアップして今回大変」**（あるあるの積み重ねで語る）

### ⑦ 感情・リアクションのこぼし方（怒り・しんどい・テンション）
出来事に対する感情を、キャバ嬢がこぼす感じの語尾・ノリで言う。**これがギャップの主戦場**。おじさんの怒りや疲れも、この言い方に乗せる。

| 場面 | キャバ嬢っぽい言い方 |
|------|------|
| しんどい・疲れた | **「ほんましんどい」「まじ無理」「もう無理むり」「限界すぎ」「もう泣きそう」「ほんまに疲れた」「しんどすぎて死にそう」** |
| 腹が立った | **「まじ無理なんやけど」「は？ってなった」「イライラすぎ」「怖すぎ」「ありえん」「ほんま勘弁して」** |
| 最悪だった | **「ほんまに最悪」「やばすぎ」「ダサすぎるし外すぎる」「〜すぎてビビった」** |
| 嬉しい・テンション高い | **「まじ最高すぎ」「神やん」「テンション爆上がり」「ウキウキすぎる」「最強に〜」「幸せすぎ」** |
| 焦り | **「やばいやばい」「秒でやらな」「間に合わへん、まじで」** |
| 呆れ・自虐 | **「もういい、ぐっちゃぐちゃ」「ほんまにやめたい（けどやめられん）」「われながらどうかと思う」** |
| 共感を誘う | **「〜くない？」「〜すぎひん？」「〜ってけんじだけ？」** |

> ポイント：**怒り・しんどさを"重く"語らない**。キャバ嬢は深刻なこともサラッと軽いテンションでこぼす。おじさんの重めの出来事ほど、この軽さとのギャップで面白くなる。

## 語彙・言い回し辞書（単語レベル）

普通の言葉を、右の語彙に置き換える。これが等身大の質感の核心。

### 強調・程度
| 普通 | 置き換え |
|------|--------|
| とても | **めっちゃ / ほんまに / マジで / バリ**（バリすっきり・バリ痛い・バリ明るい） |
| 〜すぎる | **〜すぎ / 〜すぎて死にそう / 〜すぎて死んでた**（激重・楽しみすぎ・眠すぎ） |
| 最高 | **最強に〜（美味しい）／ 最高 ／ 神〜（超神シャンプー）** |
| すぐに | **秒で〜**（秒でなくなる・秒で予定立てた・秒で寝よ・速攻） |
| 段違い | **レベチ** |
| 激しく〜する | **爆〜**（爆買い・爆食・爆睡） |
| めちゃくちゃ〜してる | **〜し散らかしてる**（ビビリ散らかしてる） |

### 状態・動き（オノマトペ・畳語）
| 普通 | 置き換え |
|------|--------|
| だらける | **グーたら / ゴロゴロ / ダラダラ / チンタラ** |
| わくわく | **ウキウキ / ワクワク** |
| 疲れ顔 | **顔が寄ってる** |
| 声がかれた | **声ガスガス** |
| 気分が沈む | **気分下げ下げ** |
| 散らかった | **ぐっちゃぐちゃ / ぐちゃぐちゃ** |
| ふわふわ | **モフモフ** |
| 手早く | **パッパッと** |
| 満腹のお腹 | **妊婦（また妊婦なってもうた）** |
| 仕方なく | **しゃーなし** |

### 動き・行動
| 普通 | 置き換え |
|------|--------|
| 出かける | **〜行ってきまーす / 速攻〜 / ダッシュで〜** |
| 〜する（実況） | **〜していくよ / 〜するよー / 〜やっていくよ** |
| 買う | **ゲット（〜ゲット）** |
| たくさん買う | **爆買い / 買いすぎて荷物激重** |
| 食べ始める | **いただきまーす** |
| 無理やり連れて行かれる | **連行させられた** |

### 大阪弁の文法・語尾（そのまま使う）

## 構成テンプレート

```
【オープニング（固定型・セルフ訂正ギャグ）】
「21歳キャバ嬢…あっ、違う違うっ、41歳〔自分のジャンル〕オーナー、〔その日の状況〕のVlog〜。」

【起床・状態報告（1〜2文）】
何時に起きた＋今日のコンディション（寝すぎ／早起きできた／疲れ／締切前）。
自虐や素直な一言を添える。

【時系列の展開（3〜6ブロック）】
つなぎ言葉（まず/ほんで/やっと/一旦…）＋行動の実況＋感想。
・各ブロックのどこかに「うまい言い切り・比喩」を1つ入れる。
・全体で1〜2回「みんなは〜する？／〜教えて」の問いかけを入れる。
・どこかにご飯シーン（食レポ）を入れる。

【締め（2文・固定型）】
「今日も〔一瞬過ぎた／楽しかった／いい休日すぎた／お仕事頑張ろう〕。」
→「みんな最後まで見てくれてありがとう。」
```

### オープニングの型（固定。◯◯だけ差し替える）
「21歳キャバ嬢…あっ、違う違うっ、41歳〔自分のジャンル〕オーナー、**◯◯**のVlog〜。」
◯◯の例（毎回変わる、その日の中心の出来事）：新作撮影する日／サンプル届く日／展示会準備する日／検品する日／発送作業の日／お揃いコーデ撮影する日／打ち合わせ行く日／お休みの日／〔その日の出来事をそのままタイトル化〕（例：台風に吹っ飛ばされた日）

### 締めの一言バリエーション（「ありがとう」の直前）
- 「今日も1日一瞬過ぎた。」
- 「今日も楽しかったん。」
- 「今日もいい休日すぎた。」
- 「朝から動き回っていい1日過ぎた。」
- 「（このあと仕事なら）今日もお仕事頑張ろう。」／「〜お仕事行ってきまーす。」
- 「（就寝なら）秒で寝よ。」

### 視聴者への問いかけ（1本に1〜2回）
- **コメント誘導の定番形（推奨）**：「**みんなの思う〜、どこ（何）をコメントで教えて〜。**」
  例：「みんなの思う日本一の餃子のお店、どこをコメントで教えて〜。」／「みんなのお揃いコーデ、どんなん着てるかコメントで教えて〜。」
  ※食レポや好みの話題のあとに置くと効く。「〜あったら教えて」より **「コメントで教えて」** を優先。
- 「みんなは〜する？／したことある？」
- 「〜ってけんじだけ？」（共感を誘う）
- 「〜くない？／〜すぎひん？」（同意を誘う）

## 出力形式

台本本文は **1フレーズ1行**で改行し、**シーンの切れ目は空行**を入れて読みやすく・編集カードに貼りやすくする。長い文は意味の切れ目で分ける。

```
【タイトル案】
①（メイン・出来事をそのまま／自虐で／問いかけで）
②（サブ案）

【台本】
（オープニング定型）
（起床・状態）
（時系列ブロック…）
（締めの一言）
みんな最後まで見てくれてありがとう。

【使った言い回し】
・〜（この台本で使った"うまい言い切り・比喩"を2〜3個メモ）
```

### タイトルの付け方（実例より）
- 出来事そのまま：「やっと引っ越しブイログ」「初のよもぎ蒸し最高すぎた」「地元で遊んだ日」
- 自虐・こぼれ話：「仕事終わり帰ってきたら絶対家汚い」「引っ越し悩みすぎて滅‼」
- 問いかけ：「みんなは兄弟でお金の貸し借りとかする」「冷凍したお肉って臭く感じるのけんじだけ？？」
- ハッシュタグ併記も可：「#41歳〔自分のジャンル〕オーナー #1日Vlog」

## けんじ台本・完成例（50秒・約300字）

けんじ本人の1日を、ギャップ・ギャル語尾・短さすべて効かせた完成形。**この粒度・テンポ・語尾を基準にする。**

```
21歳キャバ嬢…あっ、違う違うっ、41歳〔自分のジャンル〕オーナー、新作撮影する日のVlog〜。

昨日早よ寝たから今日はすっきり〜。
息子と準備して、車乗って「今日は頑張るぞ」で出発ぅ〜。

会社着いて、めっちゃいっぱいカメラ用意して撮影〜。
AIが追っかけてくれるからほんま楽ぅ〜。
新作は親子でお揃いできる服、可愛すぎて楽しすぎたぁ〜。

ほんでこの日、サッカー日本代表戦あってん。
撮影ギリギリでお昼ゲットして帰宅、ちょうどキックオフ〜。
4対0でまじ最高ぉ〜。息子も嬉しそうで、けんじも泣きそうやったぁ〜。

そのあと琵琶湖で水鉄砲〜。走り回されてヘトヘト〜。
「服はいいで」言うたのに顔ドボドボ、冷たすぎぃ〜。
服は防水やのに顔は無防備やってん。

お腹空いたから、お気に入りのラーメン屋行くよ〜。
ここの餃子、けんじ的に日本一やねん、安定の優勝ぉ〜。
みんなの思う日本一の餃子のお店、どこをコメントで教えて〜。

締めは銭湯でサウナ〜。今日の疲れバリ取れたぁ〜。

今日も1日一瞬過ぎたぁ〜。
みんな最後まで見てくれてありがとぉ〜。
```

この例のポイント：**寄り道は削る**（佐川回収・遊具・味噌ラーメン等はカット）／オチの言い切り「服は防水やのに顔は無防備やってん」を1つ立てる／食レポ＋コメント誘導をセットで置く／固有名詞は「車」「サッカー日本代表戦」で伝わりやすく。

## 長さの目安

| 尺 | 文字数目安 | ブロック数 |
|----|-----------|-----------|
| 短め（15〜30秒） | 120〜200字 | 3〜4ブロック |
| 標準（40〜50秒） | **250〜320字** | 4〜5ブロック |
| 長め（60秒前後） | 350〜430字 | 5〜6ブロック |

**実尺は思ったより字数が乗らない。「50秒」と言われたら300字前後を上限の目安にする**（早口でも350字を超えると尺オーバーしがち）。ナレーション台本は**削る前提**で、寄り道エピソード（移動・立ち寄り・脇の食レポ）は削り、コア（テーマの出来事＋オチになる言い切り＋食レポ1つ＋締め）を優先して残す。字数が余ったら足す。

## 出す前の書き癖チェック

成果物の文章を出す前に、下の問いで自分の文を見直してから渡す。手順の中身は変えない。特別なファイルやプログラムは要らない（Mac・Windowsどちらでも同じようにやる）。

- **見直す文**：書いた台本（［全部］の問いだけ）。大阪弁・ギャル語尾・話し言葉・体言止めの実況・冒頭と締めの決まり文句は、このスキルの決まりどおりでよい
- **見直さない物**：表の数字・コード・ファイル名、文字起こし、参考投稿の引用、ユーザーが書いた原文。これらは書き換えずにそのまま残す（ただし表の数字と本文の数字が食い違っていないかは、問い5で見る）。題名・回の名前・商品名のように、目次や他の回・サイトとつながっている名前も勝手に変えず、直したいときはユーザーに聞く
- **いつ**：成果物を出す前に、全体を1周＋直した所の確かめ。途中の返事・確認の質問・作業の報告には当てない
- **スキルの決まりが先**：このスキルが決めている口調（話し言葉・方言・コーチの口調など）・改行・文字数・見出しの形・絵文字、そして台本や文面の型（締めの決まり文句・余韻や「つづく」の締め・わざと繰り返す言葉・気持ちをそのまま言う独白・問いかけ・必ず残すと決めた注記や欄）は、下の問いより先に守る。問いで見るのは、意味が伝わるか・事実が正しいかだけ

### 見直しの問い（20）

問いには2種類ある。**［全部］**は台本・ストーリーズ・報告書のどれにも当てる。**［説明］**は報告書・設計書・指摘文・改善案のような、何かを説明する文だけに当てる（台本・ストーリーズの文面には当てない）。

**名前と番号**
1. ［全部］最初に付けた呼び名を、最後まで同じ名前で使っているか。1つの言葉で2つの別の物を指していないか
2. ［全部］①②…や「1つ目・2つ目」の番号が、別々の物にかぶっていないか。番号は出てくる順に1から振ってあるか
3. ［全部］初めて読む人が何のことか分からない言葉が、説明なしで出ていないか。「さっきの例」「前の回で話した」のように、前の話を覚えている前提で書いていないか。「書き出した10個」「決めた場所」のように、この文章の中で作っていない物を、もうある物として指していないか。見出し・図の札・矢印の横の短い一言も含めて上から読み、札の「これ」「それ」は札が置かれた位置から読んで何を指すか分かるかで確かめる。人を記号で呼ばず、中身で呼んでいるか（例：「夜しか撮影できない会社員」）

**事実と数字**
4. ［全部］数字・出来事・セリフは、ユーザーの発言、渡された材料、このスキルが作ったファイルのどれかにあるか。どこにも無い物は書かない。どうしても要る時は〔要確認〕を付けてユーザーに聞く。文字数・枚数・秒数のように数えられる物は、書く前に実際に数える（「〜なら大丈夫」とぼかさない）
5. ［全部］同じ物の数字・期間・回数が、場所によって違っていないか（例：「3ヶ月」と「半年」）。数字だけでなく、前の段落や別の欄で言い切ったことと、あとの文が食い違っていないか（例：「やらなくていい」と言ったあとで、それをやった例を出す）。「〜しなくてよい」「〜だけでいい」と言い切った所は、後ろの段にそれを打ち消す例が出てこないかを最後まで追う
6. ［全部］「誰も」「必ず」「絶対」「〜しかない」と言い切った文に、当てはまらない例を1つでも思いつけるなら、条件を付けて言い直す。台本・文面の話し言葉でも、体・肌・お金・効き目について「〜する」「〜しない」「〜が残る」と言い切った所は同じ。言い換えのついでに、元に無かった言い切りを足さない
7. ［全部］その仕事やジャンルの経験者（美容師・飲食店の人・子育て中の親など）が読んで、直したくなる所はないか。道具やアプリの使い方、手間や値段の比べ方、届くまでの日数などが、現実のやり方と合っているか。よく知らない道具や仕組みは名前を書かず、ユーザーに聞く
8. ［説明］数字を出したら、それが読む人にとってどういうことか（多いのか少ないのか、何と比べてか、だから何をするのか）を同じ所で言っているか。数字だけを置いて先へ進んでいないか

**理由とつながり**
9. ［説明］言い切った文のそばに、そう言える理由があるか。「AだからB」「Aと言い直すとBになる」のAからBへの一歩を、読む人が自分で踏めるか（自分で別の例を1つ作り、同じ言い直しができるか試す。できないなら、間の一歩を文で足す）。「ので」の前が、結論を言い換えただけになっていないか。すぐ後ろで別の仕組みを説明しているなら、そちらが本当の理由なので、理由の文をそちらに合わせる。1つの結論に理由が2つ以上あるなら食い違っていないか。見出しと本文で、原因の説明が別々になっていないか
10. ［説明］ひとまとまり（1つの段落・1つの欄）で言いたいことは1つか。2文目・3文目は、1文目を読んだ人が次に聞きたくなること（理由・その先どうなるか）に答えて話を進めているか。事実を1行ずつ並べて終わり、行と行の関係を読む人任せにしていないか
11. ［全部］見出しと本文で、言っていることが同じか。比べる2つが同じ物差しで並んでいるか（片方は2つの組み合わせ、もう片方は3つ、になっていないか）。主語と述語がかみ合っているか（「見せ方が埋まる」のように、何が何をしたのか読めない文になっていないか）。言葉が途中で抜けて、意味が取れなくなった文はないか（短い札や実況の言い切りは問題にしない）

**話し方**
12. ［全部］1本の中で、話し方が途中で入れ替わっていないか（です・ます と だ・である、標準語と方言、話し言葉と書き言葉）。告知の枚・お願い・DMの締めだけ、急にかしこまった言い方やお店の決まり文句に変わっていないか。スキルが話し方を決めているなら、始めから終わりまでそれで通す。ただし揃えるのはスキルが決めた範囲だけ。お礼・お詫び・独白・締めの一言で、わざと違う言い方をしている所まで平らにしない
13. ［全部］ひねった言い方や作る側だけが分かる言葉（「角度」「解像度」「横断して」など）を、まっすぐな言い方にしたか（例：「この人に向けて作ります」）。人や物ではなく、雰囲気の言葉（「この景色」「あの日の自分」「ブランドの想い」など）が文の頭に立って、詩のようにまとめた文はないか（その場で目に見える物・人の動きで書く）。たとえ話を出したら、すぐあとで本当の言葉（実際の画面・物・数字）に言い直し、そのあとの段落や枚までたとえを使い続けていないか。本文に「下書き」「確認用」のような作業のメモが入っていないか
14. ［全部］読む人にお願いする文（登録して・保存して・待機して・コメントして）に、なぜ今それをやるのか（やらないと何が困るか、やると何が楽か）が、その文か近くに添えてあるか
15. ［全部］参考や見本から借りたのは組み立て（順番・長さ・間の取り方）だけか。スキルが「残す」と決めた型の外で、参考の言い回しをそのまま、または語尾だけ変えて使っていないか。その文の中身を、この人が話したどの一言・渡されたどの材料から取ったか言えるかで確かめる

**読む人への向き方**
16. ［説明］「このあと説明します」「ここからが大事です」のように、次の話を予告するだけの文はないか。その文を抜いて読み直しても話が通じるなら消す。同じことを言い直しているだけの所は、1つにまとめる
17. ［説明］読む人の頭の中を言い当てる文（「〜と思っていませんか」「〜で止まりがちです」）や、持ち上げるだけの文（「さすがの着眼点です」）はないか。言いたい中身があるなら、何ができているかを実際の数字や画面の言葉で書く
18. ［説明］改善案や「こうするといい」の文は、画面に何が映るか・誰が何をするかまで書いてあるか。「いい雰囲気に」「前向きに」「伝わるように」で止まっていないか

**並べたときと締め**
19. ［全部］何本・何枚も並ぶ物（ストーリーズの各枚、台本や案の一覧、各回・各章の書き出し）を続けて読んで、書き出しや締めが同じ言葉・同じ形のくり返しになっていないか。同じお願い・同じ決まり文句の締めが続くなら、何枚かは中身（新しい事実・次にやること）で終える
20. ［説明］最後の段落に、読んだ人が次にやること（どこを開いて何をするか）が書いてあるか。「頑張りましょう」「きっと伝わるはず」だけで終わっていないか

### 当てはまった文の直し方

- 直す前に、その文がスキルの決まりで「そのまま」とした欄・締め・独白・ほめ言葉に入っていないかを先に見る。入っていれば、事実の誤り以外は触らない
- 直す前に、その行・その枚が何のためにあるか（怖がらせる・買ってもらう・次を待ってもらう・ほめる）を1行で言う。消すのは間違いだけ。直したあとの文が、元の文の役目（ほめる・背中を押す・怖さや期待の山を作る・言い切って決めさせる）をまだ果たしているかを確かめる。言い切りを「〜しやすい」「〜かもしれません」に弱めて済ませない
- その文は捨てて、伝えたいことを1行で言い直してから新しく書く。似た言葉に入れ替えるだけ・後ろに言葉を足すだけで済ませない（文の「誰が・何を・どうする」を1行で言えないときも同じ）。伝えたい中身が無い文は消す
- 図の札・短い一言は、指す物を取り違えるときと事実が違うときだけ直す。別の段の話や、書かなくても分かる前提を札に足さない。気分を上げる一言を、すぐ上と同じ説明に置き換えない
- 名前・番号・数字のずれは、最初に決めた1つに**全文で**揃える（1か所だけ直すと、別の場所とまたずれる）
- 材料が足りなくて正しく書けない事実は、作らずにユーザーに聞く。確かめが取れない行も、消したり空欄にしたりせず、残したまま〔要確認〕を付ける（手本の行・冒頭の引きのように役目のある行は特に）
- 直した文とその前後だけ、もう一度問いを当てる。直したことで新しいずれが出ていないかを見る。もう一度直し直すときは、前に直した所の一覧と照らし、理由なく元に戻った所が無いかを確かめる

### 出すとき

成果物を出し終えたあと、返事のいちばん最後に1行空けて、次の1行を添える。報告書・台本・文面の中には書かない。

`書き方の見直し：◯か所直しました（名前のずれ・数字の食い違い・意味の取れない文など）`

直す所が無かった時は `書き方の見直し：直す所はありませんでした`。
