# ネタ帳（言い回し・例え話・ユーモアの在庫）

## このファイルの使い方（★重要）

1. **そのまま貼る辞書として使わない。**「型の説明＋言い換え候補」として読み、**自分の言葉に変形させる**
   （そのまま使うと受講生全員が同じ文体になって、かえって薄くなる）
2. 文面を作るたびに、使った言い回し・フック・入り方を「使用ログ」に追記する
3. 次に作るときは**使用ログの直近30件を読んで、同じものを繰り返さない**
4. `stories-bunseki` で参考アカを分析したら、そこで拾った言い回しを「ユーザー由来」に追記する
   → 基本は下の在庫、提出があればユーザーの好みに寄せて**組み合わせる**

## 在庫D：正直さ（信頼を作る一言）

「（もちろん他にもしたことは沢山ある）」／「ハズレの◯◯が8割だったけど2割のために買ってるまである。笑」／
「正直、最初の1週間は微妙だった」／「正直◯◯も沢山遠回りしたし、無駄なお金も沢山使った」／
「うすーくつきます」（デメリット質問にまず正直に認める）／「中身すっからかんな◯◯もあるから気をつけてね」

## 在庫E：★橋の1行（自分の話を読者の話に変える）※これが無いと自分語りで終わる

「これは全員に言えることで」／「みーんな◯◯！でも自分に自信がないだけ」／
「って事を周りも分かってあげてほしい」／「昔の私と同じように◯◯な人の」／
「同じ悩みを持ってるフォロワちゃんの役に立てる」／「こういう経験ある人いると思うんだけど」
※最後のものは**例のひとつ**。毎回これを使わない。日々の出来事から自分のジャンルへ持っていければ形は自由。

## 在庫F：1枚目のフック（5型）

| 型 | 例 |
|---|---|
| 損を見せる | 「作り置き、3日で全部だめにした…」 |
| 数字を出す | 「2万円、無駄にしてたことに今日気づいた」 |
| 途中で切る | 「これ、言うか迷ったんだけど」（使いすぎ注意） |
| 名指しする | 「◯◯が続かない人、これだけ見て」 |
| 意外なことを言う | 「作り置き、作る日は関係ない」（本文で必ず回収する） |

## 在庫G：例え話のストック

| 伝えたいこと | 例え話 |
|---|---|
| 実績を出す理由 | 知らない人に言われたら無視する助言も、いつもの靴屋の店員なら聞く |
| 手段より結果を語る | 「駅から徒歩8分・南向き」より「朝、洗濯物を干してから出られますよ」 |
| 値段の見せ方 | 「1本5万円」より「30年使う歯なので1年1,600円くらい」 |
| 文字を置く場所 | テレビは上に速報・下に字幕。真ん中はいつも空いている |
| 一度に読ませる量 | 高速道路の看板は「東京 50km」しか書いていない |
| コントラスト | 曇り空をバックに白いシャツを干すと、どこにあるか分からない |
| 売り込みの前に置く話 | 試食を配る人は、配っている間、一度も売り込んでいない |
| 問いかけの返しやすさ | 壁当てはキャッチボールではない。相手が投げ返せる球を投げる |
| 今日の締めが明日の入り口 | 連続ドラマの次回予告 |
| 雰囲気は自分で作る | ストリートミュージシャンは帽子に最初からチップを入れておく |

## 在庫H：構造のネタ（枚の組み立て方）

- **経緯フローチャート**：白い箱の中に「⋮」で流れを縦に並べ、最後に「あの時◯◯した自分を褒めたい…ってくらい役に立った」
- **2軸比較**：色帯で2つの人物像を対比し、最後は自分の願望で言い切る
- **名言シェア**：「私が好きな言葉があるのでシェアします」→ 鍵括弧で1行 → なぜ好きか → 自分の解釈 → 一般化
- **実績の箇条書き**：この1年で…／◯◯を経験／◯kg→◯kg／◯から◯へ、と縦に並べる
- **思い込み反転**：「◯◯だと思っていたけど…」→ 図解や事実 → 「実は△△だった」
- **コスパ計算**：「朝晩使って1ヶ月／私は朝だけなので2ヶ月持つ → コスパ最強」
