# 訴求の流れ（3週間の土台 → 10日間の興味づけ → 訴求当日 → 感想集め）

出典：インスタの教科書 STEP16（16-5・16-6・16-7・16-9）。見本は `mihon_kotone.md`（架空の発信者ことね）。
**型は拡声器。** 声を大きくする道具であって、声そのものではない。信用があるところに型を足すと伸びる。

---

## 0. 聞き取り（設計に入る前）

### 必ず聞く
1. 商品のURL（公式ページ・ASPのページ）
2. 訴求日と、取れる期間（最大4週間＋α）
3. **自分で使った経験**：いつから／何がどう変わったか／**うまくいかなかった時期**
4. **そのときの気持ち**：使う前に何に困っていたか、初めて使った日にどう思ったか
5. **Before → After の経験談**（写真があるか。無ければ今日撮る）
6. 感想（家族・友人・フォロワーの声。スクショがあるか）
7. 文体の希望（いつもの自分の文章を1つ貼ってもらうと早い）

### 足りないときは「おまかせモード」
話せることが少なくても、URLを読み込んで組み立てる。ただし**体験していないことは書かない。**
- 体験が入る枚は **【ここにあなたの体験：◯◯を1〜2行】** と空けて渡す（何を書けばいいかの問いも添える）
- 体験が要らない角度（公式の情報の噛み砕き・使い方の解説・Q&A・「これから試す」実況）を多めに使う
- 使っていない商品を勧めるのは、全部の紹介の信用を消す。「まず◯週間使ってみて、記録を残してください」を先に提案する（アフィリエイトの既定）
- ★**見本（`mihon_kotone.md`）の体験・数字・感想は、文面に流用しない。**見本は架空の発信者のもの。ジャンルが同じでも、使ってよいのは「枚の並び」と「見せ方」だけ
- 感想や体験が【空欄】のまま文面を渡すときは、最後に「空欄が残っている枚：◯枚目・◯枚目」と一覧で伝える（当日チェックの「感想を1つでも入れたか」は、空欄が埋まるまで未完了）

### 自分の商品（stories-launch）で使うときの読み替え
- 「商品のURL・ASPのページ」→ 自分の販売ページ・LP（無ければ商品の説明の文章）
- 「まず◯週間使ってみて」→ 「作った過程」「先に試してくれた人・教えた人の結果」を材料にする
- 「PR」表記 → 自分の商品なので不要
- 「ASPリンクの事故」→ 関係ない（自分の販売ページ・公式LINEのリンクを貼る）

## 1. 信用の土台（訴求の3週間前から・16-5）

勧めるものに関係する**自分の考え方を3つ**決めて、**1週に1つずつ**、商品名を出さずに話す。

例（食材宅配を勧める場合）
- 1週目：時間を食っているのは「考える時間」（「作るのは20分。でも決めるのに30分かかってた。逆じゃない？」）
- 2週目：まとめてやると平日が軽い（「作り置きって、料理の技術じゃなくて段取りの話だと思ってる」）
- 3週目：時間を買うのは贅沢じゃない（「時短家電を買うのを3年迷ってた」）

3週間見ていた人には、4週目に出てくる商品が「いま自分に必要なもの」に見える。
同時に、**誰に向けて話すか**を4つ書き出す：手に入れたい未来／いま抱えている悩み（具体的な場面）／いまの状態（何を試してダメだったか）／**当てはまらない人**。「当てはまらない人」が書けると、言葉が鋭くなり「この人は合わない人に売らない」という信用になる。

## 2. 興味づけの10日間（16-6）

訴求日をX日として逆算。**1日1枚でいい。**

| 日 | やること |
|---|---|
| X-10 | 質問スタンプ（商品の気配ゼロ）「平日の夜、いちばん時間を食ってるのって何だと思う？」 |
| X-9 | 昨日の回答を紹介 |
| X-8 | ふつうの日常（**商品の話をしない日を必ず挟む**） |
| X-7 | 匂わせ①「最近◯◯が変わった。理由は今度ちゃんと話すね」＋待たせる理由 |
| X-6 | 来たDMを掲載（本物のスクショ） |
| X-5 | 使っている手元だけ映す。商品名は見せない |
| X-4 | うまくいかなかった話を先に出す |
| X-3 | 何が変わったかを1つだけ（数字で） |
| X-2 | 日付を出して予告 |
| X-1 | 「明日です」＋質問を集める |

匂わせのコツ：日付を言わずに引っ張るのは**2回まで**／待たせる**理由**を言う／**隠すのは商品名だけ**（9割分かって1割だけ分からない状態が、いちばん気になる）。
頻度：ストーリーズは毎日・1日最低5枚・商品の話は週2回（理想4回）・**日常7割、商品3割**。

## 3. 訴求当日の7つの順番（16-7）

1. **合図を出す** …「お待たせしました」で始める（ここで説得が要るなら準備不足）
2. **解決策を出す** … **3枚以内にリンク**。買う気になった人を待たせない
3. **問題提起** … なぜ勧めるのか。**自分がどう困っていたか**から（商品の説明から入らない）
4. **危機感** … このままだとどうなるか。「いつまでに」という区切り
5. **未来を見せる** … 手に入れたあと。**③④より先に出さない**
6. **使った人の声** … 本物の感想（1件目の訴求では家族・身近な人の反応で十分）＋正直なマイナスの話
7. **自分の考えで締める** … **最後の1枚をリンクにしない**。考え方に戻す

期限・個数の限りがあれば、最後のリンクの前にもう1度はっきり書く。「#PR」は画像に入れず、投稿するときに本人が右上に入れる（入れる枚を文面.mdで伝える）。

### 同じ商品でも、買う理由は人によって違う（＝言い換えの5パターン）

買う理由を**5つ前後**に分けて、訴求のたびに角度を変える。1つの角度だけだと、刺さらない層がまるごと残る。
例（食材宅配）：献立を考える時間を減らしたい／買い物の回数を減らしたい／食材の質にこだわりたい／食費を管理したい／重い荷物を運びたくない
→ 1回目＝時間の話、2回目＝質の話、3回目＝買った人の感想中心、4回目＝3ヶ月使ってどうだったか。**2回目、3回目のほうが売れることもある。**

### 出す前に確認する11項目

1. 1枚目は「お待たせしました」になっているか（説得から始めていないか）
2. 3枚以内にリンクがあるか
3. 商品の説明ではなく、自分の困りごとから話し始めているか
4. 「このままだとどうなるか」を1枚入れたか
5. 明るい未来を、困りごとと危機感より先に出していないか
6. 誰かの感想を1つでも入れたか
7. 最後の1枚がリンクになっていないか
8. うまくいかなかった話を1つ入れたか
9. 期限や個数の限りがある案件なら、はっきり書いたか
10. ★全部読み返して、**自分の言葉**になっているか（売る日だけ「〜が実現できます」と別人にならない）
11. 「#PR」を入れる枚（商品を紹介している枚・リンクの枚）を、文面.mdで伝えたか

⚠️ リンクの事故：ASPが発行したリンクを**開かずに**コピーする。一度開いてアドレスバーからコピーしたURLだと、クリックが正しく計測されず成果が付かないことがある。1件目は担当者に「これで合っていますか」と1度確認する。

## 4. 感想集め（訴求のあと・16-9）

いちばん売れる訴求は、他の人の「よかった」。感想は待っていても来ない。
1. スタンプで挙手してもらう（「買ってくれた人、どのくらいいるかな？」）→ 押してくれた人に1人ずつDM
2. 買った人向けの回（訴求の3日後くらい）：「届いた人へ。最初にこれだけやっておくと失敗しません」
3. 自分の変化を出し続ける（「2ヶ月経った。まだ続いてる」）
4. 質問を募集して答える

DMの形（5つ）：名前を呼ぶ／その人の行動に具体的なお礼／聞くのは1つだけ（「使ってみてどうでしたか？」）／返ってきたら自分の体験をプラスして返す／掲載の許可は軽く（「名前は伏せます」を先に言う）。
出し方：**スクショのまま**（名前とアイコンは隠す）／**良いことだけ選ばない**（「最初は微妙だった」も出す）／**1枚に1件**。
売り切れ・終了後は「あのとき買えた人、本当にラッキーでした」（次のキャンペーンの初速が変わる）。
悪い感想が来たら、無視しない：お礼から返す → 原因を一緒に探す → どうにもならなければ「合わない人もいます」と素直に言う。
