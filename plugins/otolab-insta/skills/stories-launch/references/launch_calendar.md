# ローンチカレンダー（8週間＝1ヶ月半）

## 全体像

```
販売日の8〜4週前  【プレプレローンチ】 存在すら出さない。週2〜3回だけ
販売日の3〜1週前  【プレローンチ】     信頼 → 距離 → 背中を押す。商品名はまだ出さない
販売日の7〜10日前 【ローンチ】         興味づけ5段階 → 予告 → 当日
販売後            【アフター】         感想集め → 角度を変えて再訴求
```

---

## 【プレプレローンチ】8〜4週前（4週間）

**目的は売ることではない。「この人は教えられる人だ」という事実を積み、期待値を少しずつ上げること。**

⚠️ **毎日この話をしない。息切れする。週2〜3回だけ。**
残りの日はカレンダーに「**days で通常運用**」と書く。

### 出すもの（週2〜3回・順不同で混ぜる）

| 種類 | 中身 | 例 |
|---|---|---|
| 教えた人の結果 | 「以前こう聞かれて、こう教えたら、この人がこうなった」 | 口コミを少しずつ出していく |
| 結果の解説 | その人がなぜそうなったのかを詳しく解説する回 | 有益情報の顔をした実績提示 |
| 進捗・作業 | 作っている様子。「今日も作業めっちゃ頑張ってる」「順調」 | 何を作っているかは言わない |
| 存在の匂わせ | 「それを詳しくまとめた"あるもの"を作ってます」 | ★商品名・価格・日程は一切出さない |

### この段階のルール

- 商品名・価格・販売日を**1回も出さない**
- 引っ張りすぎない。「今度話す」を繰り返さない（この段階ではまだ引っ張らない）
- 口コミは**小出し**。1回にまとめて出さない
- 期待値を「上げる」のであって「煽らない」

---

## 【プレローンチ】3〜1週前（3週間）

役割の順番どおりに積む。**商品名はまだ出さない。**

| 週 | 役割 | 使う型 | 作るもの |
|---|---|---|---|
| 3週前 | 信頼をつくる | ①有益な情報／⑦学んでいる姿 | 「この人の言うことは、だいたい合っている」 |
| 2週前 | 距離を縮める | ②過去の自分／⑥自分の考え方 | 「この人が好き」「自分にもできそう」 |
| 1週前 | 背中を押す | ③自分に使う大切さ／④挑戦の後押し | 「自分にもできそう」 |

⚠️ **3週間ずっと有益な情報を出し続けない。**信頼は溜まるが距離が縮まらない。
情報だけの関係の人は買わない。

**勧めるものに関係する話を、先に配っておく**のがこの3週間の仕事。
- 勧めるものが「時間を作る道具」なら → 時間の使い方についての自分の考えを先に出す
- 勧めるものが「学ぶ場所」なら → 自分が学んでいる姿を先に出す

---

## 【ローンチ】7〜10日前〜当日

見ている人は5つの段階のどこかにいる。**1日1段ずつ上げる。**

| 段階 | 相手 | 出すもの |
|---|---|---|
| ① | そもそも関心がない | まず土俵に上げる（質問スタンプ）。商品の話は1ミリもしない |
| ② | なんとなくこなしている | 工夫できる余地があることに気づいてもらう |
| ③ | すでに工夫している | ★ここで初めて**匂わせる**。商品名は出さない |
| ④ | 変えたいと思っている | 実物をチラッと見せる。姿勢を伝える |
| ⑤ | 買う気になっている | 訴求日。一気に全部出す |

### 10日間の型（X＝訴求日）

```
X-10  質問スタンプ。まだ商品の気配ゼロ
X-9   昨日の回答を紹介 → 自分の話に着地
X-8   ★何もしない日（ふつうの日常。商品の話をしない）
X-7   匂わせ①「最近◯◯が変わった。理由は今度ちゃんと話すね」
X-6   来たDMを掲載「何人か聞いてくれてる。ちゃんと話すので待ってて」
X-5   手元だけ映す。中身は見せない
X-4   うまくいかなかった話を先に出す
X-3   何が変わったかを1つだけ
X-2   予告。ここで日付を出す
X-1   「明日です」。前日に質問を集める
X     訴求
```

### 匂わせのコツ（3つ守る）

1. **引っ張る回数は2回まで**（3回目は訴求日にする）
2. **待たせる理由を言う**（「1ヶ月使ってから話したいから」）
3. ★**隠すのは1つだけ**（商品名だけを隠して、それ以外は全部話す）
   - ✕「すごくいいものを見つけたんだけど、まだ内緒」（何も分からないので気にならない）
   - ◯「◯◯が半分になった。何を変えたかは今度話す」（変化は分かる。手段だけ分からない）

### 頻度

- ストーリーズは毎日／1日最低5枚
- 商品に関する内容は週2回、理想は週4回
- ⚠️ **商品の話ばかりにしない。日常7割・商品3割**

---

## 訴求当日：7つの順番

**この順番は入れ替えない。**

| # | やること | 中身 |
|---|---|---|
| ① | 合図を出す | 「お待たせしました。やっと話せます」 |
| ② | 解決策を出す | ★**3枚以内にリンクを置く**（買う気の人を待たせない） |
| ③ | 問題提起 | 商品の説明ではなく、**自分がどう困っていたか**から |
| ④ | 危機感 | このままだと、どうなるか。**区切り**を見せる |
| ⑤ | 未来を見せる | ★③④より先に出さない |
| ⑥ | 使った人の声 | 1件でもあれば出す。無ければ身内の反応でも十分 |
| ⑦ | 自分の考えで締める | ★**リンクで終わらせない** |

### 出す前チェックリスト（10項目）

- [ ] 1枚目は「お待たせしました」になっているか（説得から始めていないか）
- [ ] **3枚以内にリンクがあるか**
- [ ] 商品の説明ではなく、**自分の困りごと**から話し始めているか
- [ ] 「このままだとどうなるか」を1枚入れたか
- [ ] 明るい未来の話を、③④より**先に**出していないか
- [ ] 誰かの感想を1つでも入れたか
- [ ] **最後の1枚がリンクになっていないか**
- [ ] うまくいかなかった話を1つ入れたか
- [ ] 期限や定員をはっきり書いたか
- [ ] ★**全部読み返して、自分の言葉になっているか**（売る瞬間だけ別人の言葉になっていないか）

---

## 【アフター】販売後

**売れた瞬間は終わりではなく、次の売上が始まる場所。**

1. **スタンプで挙手してもらう**（買った人が分かる）
2. **買った人向けの回を作る**（「届いた人へ。最初にこれだけやっておくと失敗しません」）
   → 買った人が失敗しなくなるので感想が良くなる。まだ買っていない人は「そこまで面倒みてくれるんだ」と思う
3. **自分の変化を出し続ける**
4. **質問を募集する**

集まった感想は次の訴求へ。⚠️ **同じ言葉を繰り返さない。角度を変える。**
1回目＝時間の話／2回目＝質の話／3回目＝買った人の感想中心／4回目＝3ヶ月使ってどうだったか

悪い感想が来ても、無かったことにしない。**合わない人にまで売ろうとしない姿勢のほうが、次の信用になる。**
