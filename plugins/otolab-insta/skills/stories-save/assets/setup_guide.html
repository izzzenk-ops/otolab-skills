ストーリー自動保存 設定ガイド

見ておきたいアカウントのInstagramストーリーを、毎朝パソコンが勝手に保存してくれるようにします。設定は1回だけ。Macなら5分ほど、Windowsは初回の準備を入れて15〜20分みておいてください。

これができるようになります

  • 1日分が1枚の画像にまとまります。「26.9.4.jpg」を開けば、その朝に取れたストーリーが全部並んで見えます
  • 消えたあとも残ります。ストーリーは24時間で消えますが、保存したものは残ります
  • リンクスタンプのURL・アンケートの選択肢・質問箱の質問も、文字で残ります

はじめる前に

  • ブラウザでInstagramにログインしておいてください。ここが一番大事です。ログアウトすると止まります
  • 非公開アカウントを見たい場合は、フォローして承認されている必要があります
  • パソコンにClaude Codeが入っていること（受講生のみなさんはもう入っています）
  • Windowsの方は「Python（パイソン）」という無料ソフトが必要です。入っていなければ python.org から入れてください。インストール画面の下にある 「Add python.exe to PATH」にチェックを入れてから「Install Now」を押すのがコツです（ここを忘れると動きません）
  • Macの方は、途中で「コマンドラインデベロッパツールをインストールしますか？」という画面が出ることがあります。あやしいものではないので「インストール」を押してください（5〜10分かかります）
  • SafariでしかInstagramにログインしていない方は、ChromeかFirefoxでもログインしておいてください。Safariのログイン情報を読むには、Macの「フルディスクアクセス」という設定を自分で変える必要があり、手間がかかります

Mac＋Chromeの方へ：途中でパスワードを聞かれます

設定の途中で「Chrome Safe Storage が…パスワードを入力してください」という小さな画面が出ることがあります。これはMacが「Chromeのログイン情報を渡していいか」を確認しているだけで、あやしいものではありません。Macを開くときのパスワードを、ご自分で入力してください（Claudeには入力できません）。

ボタンは 「常に許可」 を押してください。「許可」だけだと毎回この画面が出て、留守のあいだの自動保存が止まります。

Windowsで Chrome・Edge・Brave などを使っている方へ（Firefoxの方は読み飛ばしてOK）

WindowsのChrome系ブラウザ（Chrome・Edge・Brave・Opera・Vivaldi）は、2024年のアップデート以降、ログイン情報を他のソフトから読めない仕組みに変わりました。ブラウザ側の仕様なので、こちらでは変えられません。この中のどれかをお使いの方は、次のどちらかを選んでください。

A案（おすすめ）Firefox（無料のブラウザ）を入れて、そこでInstagramにログインするだけ。ふだんのChromeはそのまま使えます。一度ログインすれば、あとはほったらかしでOKです
B案Chromeの拡張機能「Get cookies.txt LOCALLY」（ログイン中のしるしを1回だけ書き出す道具）を入れて、Instagramを開いた状態で書き出します。ファイルはたいてい「ダウンロード」フォルダに instagram.com_cookies.txt という名前で入るので、Claudeには「ダウンロードフォルダに入っています」と伝えれば大丈夫です。ただし数か月に一度、同じ作業をやり直す必要があります

迷ったらA案にしてください。決めたら、Claudeに「A案でお願いします」と伝えれば、あとは手順を出してくれます。

設定のしかた

STEP 1

Claudeに、この言葉を送ります

ストーリー保存を設定して

Claude Codeを開いて、フォルダを聞かれたら 書類（Documents）の中の「Claude」フォルダを選んでください。そのあと下の入力欄に貼り付けて送ります。

STEP 2

聞かれたことに答えます

  • 保存したいアカウント … IDでも、プロフィールのURLをそのまま貼ってもOK。いくつでも登録できます
  • 使っているブラウザ（インスタをパソコンで見るときに開くソフト）… 見た目で答えてもOKです。
    丸くて赤青黄緑 → Chrome／青い方位磁石 → Safari（Mac）／青い波 → Edge／オレンジのキツネ → Firefox
    ふだんインスタにログインしている方を答えてください

あとはClaudeが全部やります。準備 → アカウント登録 → お試しで1回保存 → 毎朝の自動実行を登録、まで進みます。

STEP 3

できあがった画像を見て、終わりです

Claudeがその場で「26.9.4.jpg」を開いて見せてくれます。それが毎朝勝手に増えていく、というだけです。

相手がその時間ストーリーを出していないと、画像は作られません。「0枚でした」と出たら、それで正常です。故障ではありません。翌朝から自動でたまっていきます。

どこに保存されますか

書類 / Documents
└ Claude / Projects / ストーリー保存 /
   └ アカウント名 / 2026年 / 9月 /
      ├ 26.9.4.jpg   ← ★ふだん見るのはこれ（その日に取れた分が1枚に）
      └ 26.9.4/      ← 1枚ずつの元データ（ふだんは開かなくてOK）

フォルダは月ごと、画像は日ごとです。見つからないときは、Claudeに 「ストーリー保存のフォルダを開いて」 と言えば開いてくれます。（Windowsの方は OneDrive の中の「ドキュメント」に入ることがあります）

毎朝どう動きますか

保存は1日1回だけです。成功したらその日はもう動きません。パソコンが閉じていて失敗したときのために、9:00 / 9:30 / 10:30 / 12:00 / 15:00 / 19:00 の6回、様子を見にいく設定になっています（成功済みならすぐ終わります）。

朝9時にパソコンがスリープ（フタを閉じただけ）なら大丈夫です。開いたタイミングでその日ぶんがまとめて1回保存されます。

電源を切っていた場合は、その時刻の分は動きません。次の時刻に持ち越しになるので、夜19時までに一度パソコンを起動していれば取りこぼしません。Windowsの場合は、起動してから10分ほど待ってから動きます。

ファイル名は「保存した日」です。9月4日の朝に保存すれば「26.9.4.jpg」になり、その中には前の日の夜に出たストーリーも入ります（画像の下に「9/3 21:27」のように投稿された日時が出ます）。中身は投稿された時間順に並びます。

Claude Codeを開いておく必要はありません。パソコン自身が動かします。

ためたものを見返したいとき

先週のストーリーを見せて
今月のストーリーをまとめて振り返りたい

日付順に並べて、リンク先やアンケートの中身も一緒に見られるページを作って開きます。

アカウントを増やす・減らす

ストーリー保存に ○○○ を追加して
ストーリー保存から ○○○ を外して

まずは3〜5アカウントくらいから始めるのがおすすめです。

よくある質問

相手にバレませんか？

「バレません」とは言えません。この仕組みはストーリーをブラウザで開いて再生するのではなく、元のデータを取りに行くだけなので、閲覧者リストには載らない可能性が高いと考えています。ただし、何をすると閲覧者リストに載るのかはInstagramが公表しておらず、私たちも「絶対に載らない」ことを確認できていません。仕様が変われば変わります。

相手に知られたら困るアカウントには使わないでください。

動画は保存されますか？

動画そのもの（MP4）は保存しません。毎日ためると容量がすぐ重くなるためです。動画は1コマ目の静止画と「▶ 12秒」という表示で残ります。

パソコンを何日か開かなかったら？

その間のストーリーは取れません。ストーリーは24時間で消えるためです。

止まっているか気になります

ストーリー保存できてる？

この一言で、いつ何枚保存されたか・自動実行が生きているかを見てくれます。失敗していたら、保存フォルダに「⚠_保存に失敗しました.txt」ができます。失敗したとき、Macは通知が1回出ますが、Windowsは何も出ません。月に一度この一言で確かめてください。

一番多い原因はインスタのログイン切れです。パスワードを変えたときや、スマホで「すべての端末からログアウト」をしたときも切れます。パソコンのブラウザでインスタにログインし直して、Claudeに「ストーリー保存をやり直して」と言えば戻ります。

ハイライトや、前に出ていたストーリーも保存されますか？

いいえ。いま出ている24時間のストーリーだけです。ハイライトと、設定より前に消えたストーリーは取れません。

夜はパソコンを完全に切っています

Macは電源を切っていると動きません（フタを閉じるだけのスリープならOK）。1日1回、どこかでパソコンを開けば大丈夫です。

パソコンの容量は大丈夫？

画像だけなので軽いです。増えてきたら「1年より古い分は自動で消して」と言えば設定できます。

やめたくなったら？

「ストーリーの自動保存を止めて」と言えば解除できます。保存済みのものは残ります。保存フォルダごと捨ててしまっても大丈夫です。

使う前に、必ず読んでください

1. アカウントが制限される可能性があります

Instagramは「自動でアクセスして情報を集めること」を規約違反としていて、検知されるとアカウントが一時的に使えなくなることがあります（Instagramヘルプ）。このツールはInstagramの公式な連携機能ではなく、ログイン中のブラウザの情報を借りて動きます。その前提を理解したうえで、自己責任で使ってください。

仕事で使っているメインのアカウントではなく、サブのアカウントでログインした状態で使うことを強くおすすめします。心配な場合は、無理に使わなくて大丈夫です。手で保存する運用でも分析はできます。

2. 取りに行く回数を増やさないでください

1日1回だけ動くように作ってあります。「もっと頻繁に」「もっとたくさんのアカウントを」と増やすほど、制限される確率が上がります。登録するのは本当に見たいアカウントだけにしてください。

3. B案（ファイルの書き出し）を選んだ方へ

書き出したファイルは、あなたのInstagramにログインできてしまう鍵そのものです。人に送らない・クラウドの共有フォルダに置かない・使い終わったら消す。この3つを守ってください。運営に送る必要は絶対にありません。

4. 保存したものの扱い

他の人が作ったストーリーは、その人の作品です。自分の研究・分析のためだけに使ってください。人に配る・SNSに載せる・自分の投稿に使う、はしないでください。非公開アカウントの内容は特に注意してください。
