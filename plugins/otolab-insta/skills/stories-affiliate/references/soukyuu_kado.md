# 訴求角度カード（17種）と期間別カレンダー

同じ商品を、**日替わりで違う角度から**訴求するためのデッキ。
買う理由は人によって違うので、1つの角度だけだと刺さらない層がまるごと残る。

---

## カード一覧

### A 危機感型 ── このままだと数年後どうなるか
攻撃せずに危機感を作る。**「やらないこともリスク」の反転**を使う。
```
「◯◯は減る／△△の価値は下がる」
→「だから対策と行動が必要」
→「◯◯をやらない」
   ＝           ← 記号だけの行を置いて対比を作る
→「リスクがないわけでは全然ない」
→「というかどの選択にもリスクがある」
```

### B Before→After型
**写真に悩みラベルを直接書き込む**のがいちばん効く。
- 自分の写真のドアップに「◯◯が粉っぽい」「△△で肌荒れ」を直接置く
- 生々しい証拠（汚れたもの等）を丸くトリミングして重ねる
- After は丸トリミング2枚を斜めに重ねる
★Before素材は「使う前」に撮らないと二度と手に入らない。ヒアリングの場で必ず指示する

### C 理想の未来型
手に入れたあとの生活の1コマ。**③④（問題提起・危機感）の後にしか置かない。**
これだけをやると「へえ、よかったね」で終わる。

### D 出会いのきっかけ型
インスタで紹介される商品は、テレビにも店頭にもない。だから**出会いから話す**。
「どこで知って、なぜ試そうと思ったか」「半信半疑で1ヶ月使ってみた」

### E 第三者の権威型
- 「◯◯してくれた先生にも△△は良いと言われたくらい」
- **企業提供の図解をそのまま貼る**＋「〜ってことも講座で教えてもらった」
- 計測画面のスクショに**白い丸を描いて数字を囲む**

### F 思い込み反転型
「◯◯だと思っていたけど…」で自分の誤解を先に出して裏切る。
→ 図解や事実 → 「実は△△だった」

### G 質問回答型 ★訴求期間の主力
「〇〇について」のスタンプタイトルで質問を集め、**1問1枚**で答える。
答え方は必ず **①まず一言で答える → ②理由 → ③注意点や補足** の順。
- ★**デメリット質問こそチャンス。まず正直に認めてから説明する**
  「跡つきますか？」→「うすーくつきます」→「ただ履いてるうちに◯◯なので跡も残りにくくなる」
- ★**安全側の注意を必ず添える**（「違和感を感じた場合はすぐに使用を中止してくださいね」）
- 想定外の質問も拾う（「男性にも使えますか？」→「もちろんです」＋別の角度に展開）
※質問が来ないときは SKILL.md の「Gが使えないとき」を見る

### H 感想型
買った人の声。1件でもあれば出す。無ければ**身内の反応でも十分**。
「旦那が"これ続けてほしい"って言ってきた」

**見せ方（実物で確認・まめさんも参考教材でも同じことをしている）**
- もらったDMを**そのまま画像で貼る**（要約しない）
- **読ませたい行にだけ赤い下線**を引く
- 複数あるときは**①②③の丸番号**で並べる
- 相手の**成果の画面**（インサイト等）も並べると強い
- 前置きは自虐寄りに軽くする：「もらったことない長さの感想きてた❤️wwww」
- 画像の横に**一言で意味づけ**：「そもそも上手い人なのにさらに！」

### I 正直な欠点型
「正直、最初の1週間は微妙だった」「量が多くて余らせた。2週目から調整できるようになった」
★**これがあるから、他の枚が本当っぽくなる。**

### K 経緯フローチャート型
白い箱の中に「⋮」で流れを縦に並べる。
```
◯◯が向いてないと感じる
   ⋮
△△に不満（数字を入れる）
   ⋮
□□をやってみる
   ⋮
◇◇だと知る
   ⋮
いまの状態
```
→ 締め「**あの時◯◯した自分を褒めたい…ってくらい役に立った**」

### L 2軸比較型
他人を否定せず、**自分の願望として言い切る**。
```
🔥 常に行動して意欲的な人 👉 ◯◯になる
🌀 行動せず不満や愚痴ばっかり言ってる人 👉 △△のまま
→「私は前者でありたいし、これからも挑戦して行動できる人でありたい」
```

### M コスパ計算型
「朝晩使って1ヶ月／私は朝だけなので2ヶ月持つ → **コスパ最強です**」
「100万円稼ぐのが半年遅くなると600万円の機会損失」
★**価格は「◯◯円」と言わず、1日あたりに割って日用品に例える**（実物で確認）
「今なら**1日136円で（コンビニのコーヒー1杯くらい☕）**ずーっと学び続けられて」
→ 教科書13-5の⑥「値段を、費用対効果に」の実装形。**金額そのものは一度も出さない**

### S 数字で追いかける型（★実物で確認・売れ始めてからの日々の訴求）
新しい訴求文を毎日書かず、**増えていく数字を追いかけるだけで日々の訴求にする。**
```
販売3日 →「そしてなんと！」＋人数スタンプ 1251 ＋「びっくりしてます…😭🙏❤️」
販売1週間 →「そして販売開始なんと1週間で!!!」＋人数スタンプ 1607 ＋「本当に嬉しいし」
        →「明日のオフ会で今後の展望も話します」（★次への引き）
```
守ること
- **数字の直後に必ず自分の感情**を置く（数字だけだと実績自慢に見える）
- **次の行動予告に流す**（数字で終わらせない）
- ⚠️ **規模が無いうちは使わない。**数字が小さいと逆効果。
  代わりに「1人の変化」を丁寧に見せる（感想1件＋その人の画面）

### N 教育枚（商品名を1度も出さない）★期間中に必ず挟む
「裏を返せば、◯◯を整えることが△△の根本的な対策につながるということ」
「睡眠中は絶好の美容タイム／エイジングケアに欠かせない成分の分泌をケアします」
→ 商品の話をしない日として使える。これがあるから他の枚が浮き上がる

### O 実演型
- 腕にスウォッチして落ちるところを見せる
- 手のひらでとろみ・質感を見せる（**触感を言語化する**：「とろみがあるのに肌に馴染ませると軽い質感」）
- 濃さ・強さの3段階を並べる
- **対応できることを箇条書き**で列挙してから実演

### P フォロワーの声で笑う型
質問ボックスに来た笑える声に、自分のエピソードで返す。
毎日訴求で重くなった空気の**緩衝材**。期間中に1〜2回入れる。

### Q 自虐型
昔の写真を出して「何だこの写真はwww」／「◯◯の発信してる人間が何やってんだ（笑）」
→ 「やれば変わるし、全部自分次第！！！」

### R 手柄型 ★割引・保証はここで扱う
```
専用ページのバナー →「枚数制限ありで期間限定」「今年これが最安値」
→「PRするからフォロワちゃん限定で安く買えるようにしてください！！って直談判🤣 超迷惑🤣 頑張った🤣」
```
★**割引を企業の売り文句ではなく、自分がフォロワーのために取ってきた手柄として出す。**
返金保証も同じ。「◯◯って返金保証も付いてるんだって。商品に自信がある裏返しだよね」と
**評する側に回る**。

⚠️ **廃止：返金保証・割引だけの単独の訴求枚は作らない。**売られてる感が一気に出る。
必ず他のカードの中に一言として溶かすか、Rの形にする。

## 期間別カレンダー

### 1週間（★短期戦。すでに温まっている人向け。警告を出す）
```
D-7 A危機感 → D-6 F思い込み反転 → D-5 ★何もしない日
D-4 匂わせ①（商品名なし） → D-3 B Before → D-2 予告（日付を出す）
D-1「明日です」＋質問集め → D 訴求（7つの順番）
```

### 2週間（標準）
```
1週目 土台：N教育枚 / E権威 / F反転 / A危機感（★商品の気配ゼロ）
2週目 上の1週間コースをそのまま実行
```

### 3週間
```
1週目 信頼：N教育枚・E権威・①有益な情報
2週目 距離：D出会いのきっかけ・I正直な欠点・Q自虐
3週目 背中を押す：A危機感・L2軸比較・K経緯 → 匂わせ → 訴求
```

### 1ヶ月（高単価・親和性が低い案件）
```
1週目 N教育枚を中心に、商品ジャンルの知識を配る（商品名なし）
2週目 D出会い・K経緯・Q自虐で「この人が使っている」を自然に見せる
3週目 A危機感・L2軸・M コスパで価値観を置く
4週目 興味づけ10日の後半 → 訴求 → H感想・R手柄で再訴求
```

**全期間共通で守ること**
- ★**「商品の話をしない日」を必ず挟む**（N教育枚か、ふつうの日常）
- 商品の話は日常7割・商品3割
- 匂わせの引っ張りは2回まで
- 同じ角度を3回続けない

## リンクスタンプの文言

★**商品名を書かない。**「得られること／価格の驚き／感想」のどれか＋指差し👆。
- 「🔗3分無料でできる◯◯」（得られること）
- 「🔗送料込＋税込で380円😳㊙」（価格の驚き）
- 「🔗カラバリ豊富で可愛いよぉ」（感想）
- 「↓詳細はここから見れます🌙」を添える

## 訴求当日：7つの順番と10項目チェック

| # | やること |
|---|---|
| ① | 合図「お待たせしました。やっと話せます」 |
| ② | ★**3枚以内にリンク**（買う気の人を待たせない） |
| ③ | なぜ勧めるのか（商品説明ではなく**自分の困りごと**から） |
| ④ | このままだとどうなるか（区切りを見せる） |
| ⑤ | 手に入れたあとの未来（★③④より先に出さない） |
| ⑥ | 使った人の声 |
| ⑦ | 自分の考えで締める（★リンクで終わらせない） |

- [ ] 1枚目は「お待たせしました」か（説得から始めていないか）
- [ ] 3枚以内にリンクがあるか
- [ ] 自分の困りごとから話し始めているか
- [ ] 「このままだとどうなるか」を1枚入れたか
- [ ] 明るい未来を③④より先に出していないか
- [ ] 誰かの感想を1つでも入れたか
- [ ] 最後の1枚がリンクになっていないか
- [ ] うまくいかなかった話を1つ入れたか
- [ ] 期限や個数の限りをはっきり書いたか
- [ ] ★全部読み返して、自分の言葉になっているか（売る瞬間だけ別人にならない）

## 表記
`#PR` は右上に小さく。企業名を併記することもある。
背景の帯色を**商品のブランドカラーに合わせる**と馴染む。
