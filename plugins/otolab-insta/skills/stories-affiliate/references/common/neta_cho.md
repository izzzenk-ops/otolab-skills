# ネタ帳（言い回し・例え話・ユーモアの在庫）

## このファイルの使い方（★重要）

1. **そのまま貼る辞書として使わない。**「型の説明＋言い換え候補」として読み、**自分の言葉に変形させる**
   （そのまま使うと受講生全員が同じ文体になって、かえって薄くなる）
2. 使った言い回し・拾った言い回しの**記録は `neta_log.md`（同じフォルダ）に書く**
   - このファイル（neta_cho.md）は**知識の在庫**。更新のたびに上書きされるので、ここには追記しない
   - `neta_log.md` は上書きされない。ユーザーの記録だけが貯まる
3. 次に作るときは **`neta_log.md` の直近30件**を読んで、同じものを繰り返さない
4. 基本は下の在庫、ユーザーから参考の提出があれば `neta_log.md` の「ユーザー由来」と**組み合わせる**

## 在庫F：1枚目のフック（5型）

| 型 | 例 |
|---|---|
| 損を見せる | 「作り置き、3日で全部だめにした…」 |
| 数字を出す | 「2万円、無駄にしてたことに今日気づいた」 |

## 在庫G：例え話のストック

| 伝えたいこと | 例え話 |
|---|---|
| 実績を出す理由 | 知らない人に言われたら無視する助言も、いつもの靴屋の店員なら聞く |
| 手段より結果を語る | 「駅から徒歩8分・南向き」より「朝、洗濯物を干してから出られますよ」 |
| 値段の見せ方 | 「1本5万円」より「30年使う歯なので1年1,600円くらい」 |
| 文字を置く場所 | テレビは上に速報・下に字幕。真ん中はいつも空いている |
| 一度に読ませる量 | 高速道路の看板は「東京 50km」しか書いていない |
| コントラスト | 曇り空をバックに白いシャツを干すと、どこにあるか分からない |
| 売り込みの前に置く話 | 試食を配る人は、配っている間、一度も売り込んでいない |
| 問いかけの返しやすさ | 壁当てはキャッチボールではない。相手が投げ返せる球を投げる |
| 今日の締めが明日の入り口 | 連続ドラマの次回予告 |
| 雰囲気は自分で作る | ストリートミュージシャンは帽子に最初からチップを入れておく |

## 在庫H：構造のネタ（枚の組み立て方）

- **経緯フローチャート**：白い箱の中に「⋮」で流れを縦に並べ、最後に「あの時◯◯した自分を褒めたい…ってくらい役に立った」
- **2軸比較**：色帯で2つの人物像を対比し、最後は自分の願望で言い切る
- **名言シェア**：「私が好きな言葉があるのでシェアします」→ 鍵括弧で1行 → なぜ好きか → 自分の解釈 → 一般化
- **実績の箇条書き**：この1年で…／◯◯を経験／◯kg→◯kg／◯から◯へ、と縦に並べる
- **思い込み反転**：「◯◯だと思っていたけど…」→ 図解や事実 → 「実は△△だった」
- **コスパ計算**：「朝晩使って1ヶ月／私は朝だけなので2ヶ月持つ → コスパ最強」

## ★ネタが無い日の探し方（①有益な情報の枚を作るとき）

### 有益枚の合格ライン
- ✕ 調べたら出てくる**概念的なことを文字で羅列するだけ**の枚
- ◯ **今すぐ実践できる ＋ 独自の視点が入った1次情報**

例（ジャンル別の形）
- 「コンビニ別 300kcal以下の激うまランチ組み合わせ 3選」
- 「薬局で買える、肌タイプ別おすすめ◯◯まとめ」
- 「意外と知らない、便利すぎる神ショートカットまとめ」

「今すぐ実践できる」ものほど、初見の人が**自分が使うところを想像できる**ので刺さる。

### ネタが尽きたら X で探す

「ストーリーが上手い人を真似しよう」と言われても、**"上手い"は主観100%**。
それを正確に判断できる力量があるなら、そもそもストーリーには困っていない。
人のストーリーを見ても**実際にどれくらい反応が来ているかが見えない**ので、その情報に本当に価値があるか判断できない。

だから、**反応が数字で見える場所**で探す。

1. Xで自分のジャンル名を検索して「話題」を見る
2. 出てきた発信者のアカウントに飛ぶ
3. **いいね数・リポスト数が多い投稿**を見る（まとめ投稿にまとまっていることが多い）
4. その内容を、自分の体験と独自の視点を足してストーリーズに翻訳する

Xが向いている理由：いいね・リポストが可視化されている／まとめ投稿が多い／
ジャンル別に有益な発信者が多い／**文字ベースなのでストーリーズに応用しやすい**

⚠️ そのまま写さない。**自分がやってみた結果と、自分の見方**を必ず足す。
