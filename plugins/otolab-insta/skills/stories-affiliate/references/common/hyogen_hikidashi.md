# 見せ方の引き出し（frames.js の部品）と配分

売れているストーリーズの実物を1コマずつ数えて集めた見せ方。**1本の中で混ぜて、全部同じ見た目にしない。**

## 文字の部品

| 部品 | 書き方 | いつ使う |
|---|---|---|
| 本文の段落 | `['p','…<br>…']` | 基本。小さめの白文字。経緯・想いは5〜10行でもいい |
| 小さい補足 | `['s','（…）']` | 本音・カッコ書き・注意書き |
| 特大の見出し | `['h','…']` | フック・結論。**1本の3割以下** |
| 黒帯の見出し | `['hb','…']` | 数字の結果など、どうしても目立たせたい1行 |
| 特大の細字 | `['thin','正直に言うと…']` | 間を作る1語。1本に1回くらい |
| 白い丸札 | `['w',['…']]` | その枚でいちばん言いたい1行 |
| 白い角札 | `['wl',['…','…']]` | 対比・リスト（A → B） |
| 黒い半透明の札 | `['d',['…','…']]` | 経緯・補足を行ごとに積む |
| 赤い丸札 | `['r',['…']]` | 山場。**1本に1〜2回まで** |
| アクセント色の札 | `['o',['…']]` | 短い枚の強調。世界観の差し色 |
| 白い角札を1行ずつ積む | `['ws',['…','…']]` | 1行ずつの積み上げ・箇条書き（左寄せと相性がいい） |
| 横いっぱいの帯 | `['band',['…'],'k'または'wt']` | 状況の説明を1つの帯に |
| マーカー | 文中に `<m>…</m>` | 段落の中の一部分だけ |

## 貼り込む部品

| 部品 | 書き方 | いつ使う |
|---|---|---|
| 傾けた写真カード | `['card','photos/x.jpg',520,-4]` | 商品・本物のスクショ・Before/After（2枚並べるなら2つ置く） |
| 手描きの矢印 | `['arrow','#fff',200]` | 「これ👇」の下の写真を指す／次の枚へ引っ張る |

★**「使った人の声」は本物のスクショをカードで貼る。** DM風の吹き出しを作って文字を打ち直すと作り話になる（教科書16-9：スクショのまま出す・名前とアイコンは隠す）。

## 画像にしないもの（指示として残す）

質問スタンプ・アンケート・スライダー・カウントダウン・リンク・メンション → `sticker:'…'` と文面.md に書く。

## 配分の目安（1本＝6〜15枚の場合）

- 特大の見出し：3割以下（15枚なら4枚まで）
- 貼り込み（カード・矢印）：3〜5割
- 左寄せ：2〜3割
- 写真の背景：5〜6割／一色の背景：1〜2割
- 札の種類は3種類以上を混ぜる
- 絵文字：毎枚1〜3個（行末）
