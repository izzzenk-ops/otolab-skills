# ストーリーズのデザイン基準（v2・2026-10）

目指すのは**きれいさではなく読みやすさ**。デザインを整える目的は、おしゃれに見せることではなく**あなただと分かるようにすること**。

この基準は「既定」。**ユーザーがデザインの参考（スクショ・デザインプロファイル）を出したら、そちらを優先する。**

出典：インスタの教科書13-7（2026-10改訂）／売れているストーリーズの実物を1コマずつ数えた結果。
既定の見た目は **文字＝段落＋札、写真＝手元のアップ**（文字＝短い段落＋大事な1行だけ札やマーカー。写真＝手元のアップ・ピントは主役だけ）。

---

## 読みやすさを決める3つ

### ① 置く場所
画面の上（アイコン・名前・時間）と下（返信欄・指）はふさがっている。
→ **文字は真ん中の帯に置く。** 1080×1920の画像なら、**上は約250px、下は約340px**に文字をかけない（Metaの広告ガイド由来の目安）。
写真の主役（手元・料理など）にも文字をかけない。**主役は下半分、文字は上の空き**に置く。

### ② 一度に読ませる量
**量は決めつけない。その1枚の役割で決める。**
- 興味を引く1枚・問いかける1枚 … 1〜2行で短く
- 自分の経緯や想いを話す1枚 … 5〜10行の段落になってもいい

それでも読めるのは、量を減らしているからではなく、**読める形に整えているから**。
- いちばん読ませたい1行だけを目立たせ、残りは少し小さい文字にする
- 文節で改行して、1行を短くする（「言ってたんだよ／ね。」のような途中の改行は直す）
- 情報が並ぶときは文章にせず箇条書き
- 余白がなくなるほど詰まったら、2枚に分ける

決めるのは文字数ではなく、「この1枚でいちばん読ませたい1行はどれか」。

### ③ 文字と背景のコントラスト
写真の上の白文字は、明るい部分で消える。直し方は3つ：写真を暗くする（0.12〜0.45）／文字に札（背景色）を付ける／写真の暗い部分に寄せる。

## 文字の入れ方（既定＝段落＋札）

小さめ・細めの白文字の段落を基本にして、**目立たせるのは1枚に1か所**。目立たせ方はこの中から1つ選ぶ。

| 目立たせ方 | 使いどころ |
|---|---|
| 白い丸札（黒文字・太字） | その1枚でいちばん言いたい1行 |
| 黒い半透明の札（白文字） | 経緯・補足・ひとりごと。行ごとに積む |
| 赤い丸札 | 山場（いちばん刺したい本音・危機感）。**1本に1〜2回まで** |
| ピンクのマーカー | 段落の中の一部分だけ |
| アクセント色の札 | 自分の3色の中の差し色。13-8のような短い枚 |
| 白い角札を1行ずつ積む | 箇条書き・1行ずつの積み上げ |
| 特大の見出し | フック・結論。**1本の3割以下** |
| 特大の細字 | 間を作る1語（「さらに」「正直に言うと…」） |

行末に絵文字を1〜3個。補足は（小さいカッコ書き）で本音を足す。

## 1本の配分（実物を数えた目安）

| 項目 | 目安 |
|---|---|
| 特大の見出しがある枚 | 3割以下 |
| 何かを貼り込んだ枚（写真カード・本物のスクショ・手描きの矢印） | 3〜5割 |
| 左寄せの枚 | 2〜3割 |
| 写真の背景 | 5〜6割（そのうち人物の引きは、本人の写真がある場合だけ） |
| 一色の背景 | 1〜2割 |
| 手描きの矢印・丸 | 1〜2割 |
| 1枚の行数 | 1〜10行（役割で決める） |
| 使った人の声 | 本物のスクショで1〜2枚（打ち直さない・作らない） |

**書き出したら全部の枚の一覧（`png/一覧.png`）を見て、この配分から大きく外れていないか数える。**全部が同じ見た目になっていたら直す。

## 色とフォント

- 色は**3つまで**（世界観の3色）＋強調の差し色1つ
- フォントは**1種類**。強調は大きさか色で変える
- 毎回ちがう色にしない。揃っているほど「あなた」だと分かる

## アプリで作る人と、画像で作る人

- **アプリで作る人**：アプリの文字には影の機能がない。背景色を付けるか、背景を一色にする
- **画像で作る人（このスキルの書き出し）**：薄い影を使ってよい。札・マーカー・矢印もHTMLで描ける

## 画像にしないもの（★必ず指示として残す）

質問スタンプ・アンケート・スライダー・カウントダウン・リンク・メンションは**アプリの機能**。
画像に描くと押せない偽物になる。**文面.md に「この枚の、文字の下に◯◯を置く」と書いて残す**（下書き書き出しでは点線の目印が出る）。

## よくある崩れ方と直し方

- 文字がやたら大きい → 1枚に1つだけ大きく、あとは普通の大きさ
- 強調が多い → **1枚につき1か所**
- 余白がない → 左右に余白を残す
- 文字が主役（手元・料理）にかかっている → 文字を上に上げるか、写真を変える
- 全部同じ見た目 → 配分表を見て、札の種類・左寄せ・一色背景を混ぜる
- きれいだけど何も残らない → デザインに時間をかけるほど中身を考える時間が減る

## 練習（教科書13-7）

溜めたスクショから読みやすいものを10枚選び、**同じ見た目のものを自分で作って並べて見比べる**。真似するのはデザインだけ。文章は自分のものにする。
