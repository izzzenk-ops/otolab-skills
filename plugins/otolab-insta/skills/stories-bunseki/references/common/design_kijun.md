# ストーリーズのデザイン基準

目指すのは**きれいさではなく読みやすさ**。デザインを整える目的は、おしゃれに見せることではなく
**あなただと分かるようにすること**。

## 読みやすさを決める3つ

### ① 置く場所
画面の上（アイコン・名前・時間）と下（返信欄・指）はふさがっている。
→ **文字は画面の真ん中の帯に置く。上下2割は空ける。**

### ② 一度に読ませる量
指で送りながら流し見されている前提で書く（高速道路の看板だと思って書く）。
- 2行以上になるときは**文節で改行**
- 情報が並ぶときは文章にせず**箇条書き**
- 1枚に詰め込みそうになったら**2枚に分ける**（枚数は増えていい）

### ③ 文字と背景のコントラスト
写真の上に白文字を置くと明るい部分で消える。
直し方は3つ：背景を一色にする／文字に影か背景色をつけて浮かせる／写真の暗い部分に文字を寄せる

## 文字の載せ方は2パターンだけ（実物で確認）

- **(a) 白い帯**を写真の上に置き、その中に文字（帯＝1ブロック）
- **(b) 全面オーバーレイ**（写真全体に半透明の白か黒をかけ、その上に文字を直接置く）

## 自分のひな型（先に決めてしまう）

| 項目 | 決め方 |
|---|---|
| 背景 | 写真をそのまま／一色（迷ったら一色。速くて崩れない） |
| フォント | 1つ（多くても2つ） |
| 文字の色 | 濃い色1つ＋強調用に1つ |
| 文字の位置 | 画面の真ん中の帯。**毎回同じ高さ** |
| 色 | **3つまで**（世界観の3色をそのまま使う） |

決めておくと、考えることが「何を書くか」だけになる。**1枚30秒**で作れれば十分。

## 文字量（ユーザーに選ばせる）

選ばせる前に必ず伝える：
> 「文字が多いほうがしっかり教育がかかります。読んでくれる人を育てたいなら多め。
>  ただジャンルやキャラによっては少ないほうが読まれます。」

| 選択 | 1枚のブロック数 | 備考 |
|---|---|---|
| 多め | 6〜9ブロック | 読ませる枚。教育がいちばんかかる |
| 標準 | 3〜5ブロック | |
| 少なめ | 1〜2ブロック | **そのぶん枚数を増やす**（標準6枚→9枚程度） |

1ブロック＝1〜2行。ブロック間は1行あける。中央寄せ、左右に余白。

## よくある崩れ方と直し方

- 文字がやたら大きい → 1枚に1つだけ大きくして、あとは普通の大きさに戻す
- 装飾が多すぎる → **1枚につき強調は1箇所**
- 余白がない → 左右に少し余白を残す
- フォントが毎回ちがう → 1つか2つに決めてしまう
- きれいだけど何も残らない → デザインに時間をかけるほど中身を考える時間が減る

## 使える装飾（実物で確認）

| 装飾 | 用途 |
|---|---|
| **赤い下線** | DMや質問のスクショで、読ませたい行だけに引く（★どのジャンルでも有効） |
| 丸囲み（白い円） | 数値のスクショで見せたい数字を囲む |
| → 矢印 | 次の枚へ引っ張る |
| ⋮ 縦の点 | 経緯・流れを縦に並べる |
| ＝ 単独行 | 対比を作る |
| 縦書きの黒帯 | 他人のコンテンツのスクショの横に一言 |
| 丸トリミング | Before/Afterを2枚重ねる／生々しい証拠を重ねる |
| リンクスタンプ＋👆 | 訴求日。指差し絵文字を添える |
| 悩みラベル | Before写真の上に、悩みを直接書き込む |

## 練習（教科書13-7）

溜めたスクショから読みやすいものを10枚選び、**同じ見た目のものを自分で作って並べて見比べる**。
⚠️ 真似するのはデザインだけ。文章は自分のものにする。
