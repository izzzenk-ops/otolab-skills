# style_profile.md（見本・架空アカウント「人見知り美容師みお」）

- バズ判定: 認定（フォロワー2.8万人 × 最高89万再生 = 31.8倍。バズ認定ライン=フォロワー×10倍 or 100万再生）

## 一言コンセプト
人見知りの美容師が、話しかけられない客側の気持ちに立って「サイレント接客」の裏側を見せるVlog

## フックの型（実例つき）
- 型: 常識破壊のバーバルフック＋手元のビジュアルフック。「美容師なのに、お客さんと話したくありません」（0〜2秒・断定で開始）
- 変形パターン: 「◯◯なのに、△△できません」の告白形。数字を足すと強い（「美容師歴9年、雑談は9年間ずっと苦手です」）
- 最初の画: 顔を映さず手元のシザーケースから始める（誰の話か1秒引っ張る）

## 展開のブロック構造（秒配分つき）
1. 告白フック（0〜2秒）→ 2. 客側の「わかる」あるある（〜7秒・見続ける理由）→ 3. サイレント接客の実演（〜25秒・字幕のみ）→ 4. 種明かし＝メニュー表の工夫（〜38秒）→ 5. 締めの一言＋CTA（〜45秒）

## オチ／CTAの型
- オチ: 「話さなくても、ちゃんと伝わるんです」で価値観に着地
- CTA: 「同じ人見知りさんはコメントで🙋」→ 固定コメントでハイライト「予約の流れ」へ誘導

## 視聴者心理の設計（心理レバー・推定）
- 冒頭: 「美容師なのに話したくない？」という矛盾を植える → 理由を知りたくて見続ける
- 中盤: 無言の施術映像で「え、本当に一言も話さないの？」という検証心理 → 種明かしまで離脱しにくい
- 終盤: 「人見知りは直すものじゃなく設計で解決できる」という納得 → 同じ悩みの人が保存・コメントしたくなる
- 必ず「具体トリガー＋視聴者の頭に浮かぶ言葉「〜」＋次の行動」の粒度で書く（推定と明示）

## 文体ルール
- 一人称「わたし」。です・ます調だが語尾に「…です（小声）」の照れが混ざる
- 頻出フレーズ: 「わかります、その気まずさ」「無言、正義」
- 迂回表現: 客への否定語を使わない（「苦手なお客さん」→「緊張する時間帯」）

## 尺と文字数
- 40〜50秒／ナレーション250〜300字（1秒6字前後）
