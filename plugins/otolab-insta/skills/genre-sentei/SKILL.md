# genre-sentei｜ジャンル選定

## このスキルについて

ジャンルは「好き・やりたい」ではなく**市場の数字で決める**もの。このスキルは4スキル連携の2番目を担う：

```
insta-concept-design Phase1-2（自己分析・ジャンル候補10） → genre-sentei（本スキル・戦うジャンル確定） → concept-research（ジャンル内の企画リサーチ） → concept-brush-up（決定版） → insta-concept-design Phase3（アカウント名・プロフ）
```

流れは6ステップ。STEP 2の途中で**ユーザーのスマホ巡回待ちのため一旦停止する**のが正常な動作。

| STEP | 内容 | 詳細指示書 |
|---|---|---|
| 0 | 引き継ぎ（Phase 2 で本人が選んだ2〜3個）＋パターン①／②の分岐 | 本ファイル |
| 1 | 候補の確認（継続の事前チェック）※候補出しは Phase 2 の仕事 | 本ファイル＋`references/genre-85sen.md` |
| 2 | 市場調査（2A: Chromeでトップ層調査／2B: スマホ巡回宿題→**停止**／2C: 統合・Go/No-Go判定） | `references/research-criteria.md` |
| 3 | 収益化導線チェック＋ずらし導線設計 | `references/research-criteria.md` |
| 4 | 落とし穴チェック＋1ジャンルに確定 | 本ファイル |
| 5 | HTML報告書＋03_ジャンル選定.md 出力 | 本ファイル＋`assets/report_template.html` |

**該当STEPを始める前に必ず対応する指示書を読むこと。** 判定基準はすべて数値で書いてある。感覚で判定しない。

## 中断・再開の仕組み（最初に理解しておくこと）

- 進行状態は `00_state.md` に書く（このスキル専用の genre_state.md は廃止。2026-09-03）。STEPが進むたびに更新する
- スキル起動時は**まず `00_state.md` を読む**。「2B提出待ち」で止まっていたら 2C から再開する
- ユーザーがアカウントのリンクやスクショを貼ってきたら、それは2Bの提出物。2Cから再開する
  - ※concept-research にも同じ提出制の宿題がある。**どちらの宿題待ちかは `00_state.md` の「待ち状態」に書いてある**ので、そこで判定する

## 出力フォルダ（4スキル共通・1人1フォルダ）

**対象者ごとにフォルダは1つだけ。フォルダ名に日付を付けない。**

```
~/Documents/Claude/Projects/インスタコンセプト設計/<対象者名>/
├── 00_state.md                 ← 進行状態＋成果物の索引（全スキル共通の正本）
├── 01_自己分析レポート.md
├── 02_ジャンル候補10.md / .html  ← insta-concept-design Phase 2（このスキルの入力）
├── 03_ジャンル選定.md / 03_ジャンル選定報告書.html   ← ★このスキルの出力
├── 04_リサーチ.md / 04_リサーチ報告書.html / shots/
├── 05_コンセプト10案.html
├── 06_決定版コンセプト.md
├── 07_アカウント名_プロフィール.md
└── 宿題_スマホ巡回.md            ← 巡回の宿題を出したときの控え
```

**起動時に必ず最初にやること**

1. `<対象者名>/00_state.md` を探して読む。あれば現在地・待ち状態・確定事項がすべて分かる（他のファイルを総なめしない）
2. 無ければ**旧形式のフォルダ**を探す（`<対象者名>_<日付>` `<対象者名>_ジャンル選定_<日付>` `<対象者名>_リサーチ_<日付>`）。見つかったら中身を読んで作業は続行し、**1つのフォルダに寄せてよいかユーザーに確認してから**移す。確認なしに移動・削除しない
3. それも無ければ新規作成する

**終了時に必ずやること**：`00_state.md` を更新する（現在地・待ち状態・確定ジャンル・申し送り）。
待ち状態には**どのスキルの宿題を待っているか**を必ず書く（concept-research にも同じ提出制の宿題があるため）。

## STEP 0：引き継ぎ＋現在地判定（パターン分岐）

1. `00_state.md` と `02_ジャンル候補10.md`（insta-concept-design Phase 2 の成果物）を読む。
   - **「本人が選んだ候補」（2〜3個）がこのスキルの出発点。** ここに書かれた候補を市場の数字で検証する。ゼロから候補を出し直さない
   - 「本人が『これは無理』と言ったもの」も読む。**蒸し返さない**
   - `01_自己分析レポート.md` があれば「独自性素材シート」「発信できそうなジャンルの種」も読む
2. `02_ジャンル候補10.md` が無い場合（このスキルから直接始めた人）：
   - まず insta-concept-design の Phase 2（ジャンル候補10）を先にやることを勧める。「できそうな発信を10コ並べてから選ぶ方が、迷いが減ります」
   - それでも今すぐ進めたい・すでにジャンル候補が本人の中にある場合は、下の「候補が無いときの候補出し」で2〜3個作ってから STEP 2 へ
3. **分岐質問（このスキルの核）**：「売りたいものや、やりたい収益化の形は決まっていますか？」
   - **パターン①：まだ決まっていない** → 必ずこう伝える：「それが普通です。ほとんどの人がここからのスタートなので、始められない理由には1ミリもなりません」
   - **パターン②：明確に決まっている** → 売りたいもの・ゴールを具体的に聞く。選ばれた候補が売りたいものとつながるかを STEP 3 で見る

## STEP 1：候補の確認（※候補出しは Phase 2 の仕事）

引き継いだ2〜3個の候補について、**市場調査に入る前に継続の事前チェックだけ**を対話で行う（**1問ずつ**）：

- 「これは生活導線上にありますか？（どうせ毎日やることの"ついで"に撮れますか？）」
- 「**100投稿できるイメージが湧きますか？**」
- 基準の意味は失敗実例で伝える：「カフェ紹介のアカウントを続けるには土日に7軒回る必要があって、続かずやめてしまった人がいます。毎日の自炊のついでに撮れるレシピに変えたら続いた、という話です」

ここで明らかに続かないと本人が言った候補は外し、`02_ジャンル候補10.md` の残り8枚から代わりを1つ選んでもらう。
**今すぐ実績がなくても候補にしてよい**（実績が必要なジャンルの扱いは STEP 4 で判定する）。

### 候補が無いときの候補出し（フォールバック）

Phase 2 を通っていない人にだけ使う。`references/genre-85sen.md` を読んでから、2〜3個に絞る。

- **①ルート（売りたいものがない人）**：自己分析の棚卸しから「発信の種」を拾い、引き出しリストと突き合わせる。本人の生活・経験から出てこないジャンルを押し付けない
- **②ルート（売りたいものが明確な人）**：売りたいものから連想で関連ジャンルを広げる。直接関連だけでなく**届けたい相手が重なるジャンル**まで広げてよい（例: ショート動画教材→動画編集→撮影→写真の撮り方）

確認できた候補は `00_state.md` に記録する。

## STEP 2：市場調査（心臓部）

**開始前に必ず `references/research-criteria.md` を読む。** 数値基準・手順・罠の全てがそこにある。

- **2A（Chromeでトップ層調査）**：候補ジャンルごとに、Claude in ChromeでInstagramを**検索ベース**で巡回し、トップ層アカウント（情報発信メイン）のフォロワー数を記録する。PCのおすすめ欄・発見欄は精度が悪いので**使わない**
- **2B（スマホ巡回の宿題）**：「直近伸びているアカウント探し」は発見タブの育成が必要＝**スマホでしかできない**。`references/smartphone-homework.md` の指示書をユーザー向けに具体化して渡し、**スキルはここで一旦停止**。指示書の控えを `宿題_スマホ巡回.md` に保存、`00_state.md` の待ち状態を「genre-sentei の 2B 提出待ち」にして終了
- **2C（統合・Go/No-Go判定）**：提出が来たら再開。候補ジャンルごとに数値基準で判定表を作り、Go（合格）／No-Go（見送り）／条件付きGo（特化すれば可）を根拠つきで提示する

## STEP 3：収益化導線チェック＋ずらし導線設計

`references/research-criteria.md` の後半に従う。2Cを通過した候補ジャンルごとに：

1. 先駆者のプロフィール・ハイライト・タイアップ投稿をChromeで確認し、「**この人は何で収益化しているか**」を具体的に記録する。見つからないジャンルは危険信号として明示
2. **ずらし導線**を1〜2案設計する：「投稿＝伸びやすいジャンルでパイを取る × ストーリーズ＝収益化したいジャンルを発信」の組み合わせ
3. パターン②の人は「売りたいものへの自然な橋」を言語化する
4. 収益化の話で不安にさせない。「先駆者が収益化しているのを確認できて、イメージが湧けばOKです。考えすぎて動けなくなるのが一番もったいないです」と必ず伝える

## STEP 4：落とし穴チェック＋1ジャンルに確定

最終候補に対して3つの落とし穴を対話でチェックする（**1問ずつ**）：

1. **「伸びてるから」だけで選んでいないか**：「このジャンル、調べること自体は楽しめそうですか？」— 数字が良くても本人が興味を持てないなら外す。正解は「**伸びているジャンル×自分が続けられるジャンルの重なり**」
2. **見切り発車になっていないか**：実績・証拠が必要なジャンル（ダイエット・ビジネス・スキル系）で今の本人に見せられるものがない場合、**期限付き準備期間プラン**を提案する：
   - 最短1ヶ月・最長2ヶ月と期限を明確に決める（期限なしの「いつか準備できたら」は永遠に始まらない）
   - 期間中は毎日30分〜1時間のインプット or 実践＋素材の撮り溜め（ビフォーアフター写真など）
   - 期限が来たら完璧でなくても必ず始める
   - 実例を添える：「2ヶ月発信を止めてダイエットを実践し、ビフォーアフター素材を撮り溜めてから始めた人は、20投稿以内に1万人を達成しています」
3. **ブルーオーシャンに逃げていないか**：競合がほぼいないジャンルは、本人に専門家級の実績・資格がない限り選ばない。「競合が多い＝需要がある証拠でチャンス。競合ゼロのジャンルはそもそも誰も見ていない可能性が高いです」と明示

確定の手順：
- 3つの掟チェックリスト（**需要がある・継続できる・収益化できる**）が全部✅のジャンルだけを最終候補にする
- 迷ったら「より継続しやすい方」「収益化のイメージがより具体的な方」を勧める
- 最後は**本人に選んでもらう**：「この数字を見て、自分が続けられそうなのはどれですか？」（AIが確定しない）
- 確定したら、そのジャンル内の**特化テーマの方向性**（例:「レシピ」→「冷凍ストック×簡単レシピ」）まで軽く目星をつける。深掘りは concept-research の仕事なので、ここでは方向性1行でよい

2. `<対象者名>/03_ジャンル選定報告書.html` に保存し、Claude in Chrome の navigate で `file:///...` を開いて見せる（Chrome拡張が使えなければ `open <パス>`）
3. `<対象者名>/03_ジャンル選定.md` を以下の固定構造で保存する（concept-research が機械的に読む。旧名 genre_sentei.md は2026-09-03に改名）：


## 絶対に守るルール

- **抽象的な判定をしない。** 「伸びてそう」ではなく「トップ層10万人超が◯個」「50投稿未満で◯人のアカが◯個」と数値で言う。基準は references/research-criteria.md にある
- **有名人・個人のファンで伸びているアカウントをカウントしない。** 必ずプロフィールに飛んで情報発信メインか確認する
- **1年以上前に伸びたアカウントを根拠にしない**（「インスタの世界では化石」）
- **最終決定は本人。** AIは数字と選択肢を並べるところまで
- **フォロワー0で始められない方向は候補にしない**
- Instagram巡回では収集の罠に注意（ログイン状態の確認・リール一覧の遅延読み込み・再生数表記の単位・ポップアップ）。**壊れた取得結果から結論を出さない。** 空・矛盾したデータは取得側の問題を疑い、別ソースで裏取りする
- 励ましのトーンを要所で使う：「失敗は存在しない、すべて資産になる」「完璧を求めて動けないより、まず始めて修正する方が100倍速い」

## 言葉遣いのルール（insta-concept-design / concept-research と共通）

- **専門用語を出力に使わない。** ベンチマーク→「お手本アカウント」、ニッチ→「すき間」、マネタイズ→「収益化」など必ず日本語に言い換える
- **硬い敬語を使わない。**「させていただきます」ではなく「していきますね」。オトラボの講師が受講生に話すフレンドリーなトーン
- **数字を徹底的に集める。** フォロワー数・投稿数・再生数・アカウント数が報告書の説得力を決める
- **1問ずつ聞く。** 複数の質問を一度に投げない
