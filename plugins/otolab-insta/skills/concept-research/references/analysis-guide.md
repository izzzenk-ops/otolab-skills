## STEP 3：パターンカードの作り方

対象：2Bでユーザーが提出したアカウント（主役）＋2Aで見つけた強いアカウント（補助）。合計5〜8枚が目安。
**1枚＝1アカウント。** ユーザーがカードを見比べて「自分はこのパターンでいこう」と選べる状態がゴール。

### カードの構成（7項目）

1. **冒頭・世界観の写真**
   - Chromeでそのアカウントの代表リール（一番伸びているもの）を開き、冒頭部分をスクリーンショット → `shots/` に保存
   - サムネイル一覧（プロフィールグリッド）のスクショも1枚撮ると世界観の統一感が伝わる
   - 「第1カットに何が映っているか」を言語化する（例:「玄関ドアから入ってくる帰宅シーン・スーツ姿・照明は生活感のある暖色」）
2. **コンセプトの言語化**（1〜2行）
   - 「誰が×誰に×どのように届けているか」。例:「ズボラな一人暮らしOLが×同じ一人暮らしOLに×10分以内の時短レシピをリアルな調理のまま」
   - 「誰に×何を」だけで書かない。誰が（その人らしさ）が抜けると、誰でも言える発信の説明になる
3. **6項目の分解**（下記「6項目の読み方」を使う。2026-11-04 追加）
   - ①誰が（属性）②誰が（生い立ち・経験）③どんなことを ④どのように ⑤何が解決できるか ⑥どんな未来へ、を1行ずつ埋める
   - 講座STEP5（5-3「競合は6つで分析する」）と同じ項目。あとで受講生が同じ6項目で自分のコンセプトを書くので、項目名を変えない
4. **4要素の突出診断**（下記の診断基準を使う）
   - 世界観／企画力／編集力／独自性を◎○△で採点し、**どの1〜2個で勝っているか**を明記
5. **強みの掛け算式の逆算**
   - その発信者の特徴を「何人に1人」で分解して式を再現する（下記の手順）。①属性と②生い立ち・経験で拾った特徴を材料にする
   - ギャップの構造も1行で（「◯◯なのに◯◯」の形）
6. **数字**
   - フォロワー数／代表投稿の再生数／相対倍率（平均の何倍か）／何投稿目で伸びたか（分かれば）
7. **自分に応用するなら**
   - この人のどの要素を借りられるか（企画？世界観？映し方？）
   - 自分ならどの掛け算で同じ**構造**を作れるか（中身の丸パクリではなく構造の移植）
   - 6項目のうち、どこを借りて、どこを自分のもの（特に①②）に差し替えるか

### 6項目の読み方（2026-11-04 追加）

| # | 項目 | 何を書くか | 読み取る場所 |
|---|---|---|---|
| ① | 誰が（属性） | 年齢・仕事・家族など、いまの立場 | プロフィール文・自己紹介リール・映り込む生活 |
| ② | 誰が（生い立ち・経験） | どこで育ち、何を経てここに来たか。乗り越えた経験・珍しい境遇 | 自己紹介リール・固定投稿・ハイライト・キャプションで本人が話している範囲 |
| ③ | どんなことを | 届けている中身（ジャンルを1行で） | 投稿一覧・企画名 |
| ④ | どのように | 企画・見せ方・ビジュアル・世界観（STEP 4の編集・映し方・声・冒頭もここに入る） | 冒頭カット・グリッド・テロップ・声 |
| ⑤ | 何が解決できるか | 誰の、どんな困りごとを解決して、見た人が何を手に入れるか | 感謝コメント・保存される投稿・プロフィールの約束 |
| ⑥ | どんな未来へ | 発信する本人が、どんな未来に進もうとしているか。**期限**と**期限の理由**が出ているかも見る | プロフィールの名前・肩書き・「◯日目」「◯ヶ月後」の連載・自己紹介 |

書くときの決まり：

- **②は本人が公開している範囲だけ書く。** 推測で生い立ちを作らない。出ていなければ「投稿からは読み取れず」と書く。家族・病気・過去のつらい話は、本人が発信の中で話している言葉の範囲にとどめる
- **⑥は本人が言葉にしていなければ投稿から読み取ってよい**（例：毎回「◯日目」と数えている→期限つきで進んでいる）。読み取ったものは「（投稿からの推定）」と付ける。それでも分からなければ「読み取れず」でよい。期限も理由もAIが作らない
- **⑥の型を1つ選んで書く**（プロセスエコノミー型＝目標に向かう途中を見せる発信かどうかの見分け）

| ⑥の型 | 中身 | 例 | 強さの目安 |
|---|---|---|---|
| 期限＋理由 | 期限と、その期限で達成しないといけない理由の両方がある | 「3ヶ月後に−5kg」＋「結婚式までに」 | 強い。見る人が「間に合うのか」を追いかけて、続きを見に来る |
| 期限だけ | 期限はあるが、なぜその期限なのかが無い | 「100日後に◯◯ボディを目指す」 | 弱め。続きを見る理由が本人の気分に頼る。伸びていれば企画や見た目など別の要素が効いている可能性が高いので、4要素の診断で確かめる |
| 期限なし | 進みたい暮らし・方向だけがある | 「無理なく節約を続ける暮らし」 | 弱いわけではない。ノウハウ型・暮らし型のジャンルでは普通の形 |
| 読み取れず | 投稿からも分からない | — | 空欄にせず「読み取れず」と書く |

- ⑥はどのアカウントにも必須ではない。期限が無いお手本を「弱い」と決めつけない。期限＋理由の形がそのジャンルで伸びているかを、カードを並べて見る材料にする

### 4要素の突出診断基準（突出ポイント制）

伸びるアカウントは4要素のうち**1〜2個が100点**で、他は普通でも伸びる。全部60点は伸びない。

| 要素 | ◎（突出）の目安 | 見るところ |
|---|---|---|
| 世界観 🎨 | 見た瞬間「この人のだ」と分かる統一感。世界観だけで手が止まる | プロフィールグリッドの統一感／第1カットの作り込み／服装・小物・照明 |
| 企画力 💡 | 企画名だけで見たくなる。感謝コメントが多い | 投稿タイトル・テーマの絞り／同テーマの反復で伸びているか |
| 編集力 ✂️ | テンポ・テロップ・カットに明確なスタイルがある | カット割りの細かさ／テロップの読みやすさ／プロ感 |
| 独自性 ✨ | 「この人にしかない」要素が1行で言える | ギャップ／エピソード／珍しい掛け算 |

診断の書き方例（参考教材の実例）：
- 料理垢 @narudiary__ → 企画力◎（レンチン時短）＋独自性◎（ドア入り帰宅シーン・雑な調理の共感）、世界観○・編集力○
- 写真垢 @narumovie__ → 企画力◎＋編集力◎、世界観○・独自性○

### 掛け算式の逆算手順

1. その発信者のプロフィール・投稿・キャプションから**特徴を3〜5個**拾う（職業・年齢・性格・見た目・習慣・環境）
2. 各特徴を「何人に1人か」に感覚で数値化（10人に1人／100人に1人の粒度でよい）
3. 掛け算して「何万人に1人」かを出す
4. **ギャップの構造**を特定する：どの特徴の組み合わせが「普通イメージしない組み合わせ」になっているか

実例（講義から）：
- @ao_diary__ ＝ 中卒(100人に1人)×現場職人(10人に1人)×毎日お弁当作り(10人に1人)×20歳で発信(100人に1人)＝**1,000万人に1人**。ギャップ:「中卒×現場職人の20歳男子が毎日自分のお弁当を作る」＝イメージの真逆
- 参考教材の発信者 ＝ 毎日10時間フリーランス(100人に1人)×美人(100人に1人)×ズボラではっきりした性格(100人に1人)×20代タワマン(100人に1人)＝**1億分の1**。ギャップ:「綺麗系なのにズボラ・乱暴ワード」
- @dansuki3 ＝ コワモテ旦那×めっちゃ優しい。単体ではよくいる2要素が、組み合わせでレアになる例

ポイント：**ネガティブに見える特徴（中卒・ズボラ・訛り等）ほどギャップの材料として最強**。カードでもそのように書く。

## STEP 4：見せ方・世界観ベンチマークの選定

パターンカード群＋必要なら追加巡回から、4つを決める。すべて「本人のキャラ・条件に合うか」が第一基準。

### ① 編集テイストの参考（1人決める）
- 同じジャンルでも編集で印象が真逆になることを必ず説明する（例：同じレシピでも、動作が荒い×テンポ早い×画角変更多め＝ズボラで大胆な印象／ゆっくり×丁寧なカット＝落ち着いた丁寧な印象）
- 「どんな印象を持たれたいか」を本人に聞いてから、その印象を作っている発信者を1人特定する
- 参考を1人決めておくだけで動画クオリティの伸びが段違いに速くなる、と伝える

### ② 映し方のロールモデル（顔出し可否に合わせて）
顔出しNGでも必ず選択肢がある。5パターンから本人の条件に合うものを、実例アカウントつきで提案：
1. 顔出しなし×後ろ姿・手元にこだわる
2. 顔出しなし×服・全身のスタイルは見せる
3. 顔出しなし×表情の一部を工夫して見せる（口元・目線カットなど）
4. 顔出しなし×スタンプ・エフェクトで顔を隠す
5. 顔出しあり
- 「顔出しなしで大丈夫？」と不安がられたら：まずリサーチすると顔出しなしの成功例が大量に見つかる、と伝えてカードで実例を見せる

### ③ アフレコの目星
- 今から始めるならアフレコはほぼ必須（アフレコありの方が伸びる）
- 選択肢：自分の声（話し方のトーンの参考を1人決める）／AI音声（流行があるので今流行っているものを確認する）
- **判定基準は「キャラ・世界観に合うか」。** 流行ボイスでも本人のキャラに合わなければ不採用（乱暴系ボイスは、はっきりした性格の人には合うが、穏やかキャラの人が使うと世界観が崩れる）

### ④ 世界観3要素の方針
カードの写真を見ながら、本人の撮影環境に合わせて方針を決める：
1. **身に着けるアイテム**：服装（同じ服は2度着ないレベルでこだわる価値がある／体のラインやデコルテは冒頭フックになる）＋顔周りの小物（ヘッドフォン・帽子・メガネ・職業の制服や道具は最強のトレードマーク）
2. **映り込む小物・家具・照明**：映るもの全てに気を配る。部屋全体が無理なら**撮影テリトリーだけ**作り込む。夜は間接照明
3. **身だしなみと姿勢**：髪のツヤ・爪・姿勢。手元撮影ならハンドクリーム。逆にだらしなさで共感を取る方針ならそこにこだわる
- 参考リサーチ先も添える：スタイリング＝NUGUアプリ（ディレクター→性別絞り込み→マネキン買い）／世界観・小物＝海外リール（検索:「diary vlog korean」「lifestyle vlog」）やRED／購入＝SHEIN・TEMU（安く揃う）、家具探し＝Pinterest
- 外撮影しかできない場合：服装とヘアスタイルに集中する（参考教材と同じ判断）

## STEP 5：自分の独自性の素材出し（対話）

初期設計の**独自性素材シート**（01_自己分析レポート.md 内）があれば読み込んで出発点にする。ゼロから再ヒアリングしない。市場リサーチで見えたものに合わせて磨き直すのがこのSTEPの仕事。

### ① 特徴の数値化掛け算
1. 特徴リスト（3〜5個）を確認・不足なら追加で聞く。**「良いことじゃなくてOK。ネガティブなことほど武器になります」と必ず伝える**
2. 各特徴を「何人に1人か」に本人の感覚で数値化してもらう
3. 掛け算して「何万人に1人」を出す。目標は1,000万〜1億分の1
4. **STEP 3で逆算した成功者の式と並べて見せる**（「あおさんが1,000万分の1、あなたは今◯◯分の1」）。足りなければ「どの領域に行けば希少になるか」を一緒に探す（ジャニーズ顔もIT企業なら超イケメンエンジニア＝環境で希少性は変わる）

### ② ギャップ探索
1. 「初対面の人からどう見られることが多いですか？」と聞く（客観イメージの特定）
2. その真逆・意外性のある組み合わせを探す（美人×ズボラ／コワモテ×優しい／綺麗系×乱暴ワードの構造）
3. 掛け算できる強みが弱い人は、**見せ方・世界観のクオリティで差をつける方針に切り替える**（「誰でもできることを誰もができないレベルでやる」こと自体が希少性。普通の貯金ノウハウでも世界観統一で伸びた実例がある）

### ③ 語れるエピソード
- 「過去にやってきたこと→そこでできた価値観→今目指しているもの→今の悩み」を語れる形に整理する。「過去にやってきたこと」は6項目の②（生い立ち・経験）、「今目指しているもの」は⑥（どんな未来へ）の材料になる
- 最強の属人性はエピソード。たった1つのエピソードで印象がひっくり返る（恋愛リアリティーショーで嫌いだった人が過去エピソード1つで応援したくなる、あの現象）
- 弱み・悩みを赤裸々に出すのは大勢がやらないからこそチャンス、と背中を押す。ただし**本気で正直に**が条件（作ったエピソードは伝わらない）

### 検証3問（独自性の最終チェック）
1. この強みを同じレベルで持っている人はどれくらいいる？
2. この強みで提供できる価値を、同じように提供できる人は？
3. 真似しようとしたら、どれくらいの時間と労力がかかる？
→ 3つとも「ごくわずか」なら唯一無二。答えられなければ掛け算かギャップを作り直す

### ④ お手本3人と自分を6項目で並べる（2026-11-04 追加）

カードの中から、本人が「この方向でいきたい」と選んだお手本を3人選び（選んだのが2人なら2列でよい）、6項目を1行ずつ並べる。いちばん右に本人の6項目を書く（＝自分のコンセプトの下書き）。

| 6項目 | お手本A | お手本B | お手本C | 自分 | 判定 |
|---|---|---|---|---|---|
| ①誰が（属性） | | | | | 同じ／自分だけ |
| ②誰が（生い立ち・経験） | | | | | |
| ③どんなことを | | | | | |
| ④どのように | | | | | |
| ⑤何が解決できるか | | | | | |
| ⑥どんな未来へ | | | | | |

- 本人の①②は、01_自己分析レポートの「2-1. 生い立ち・これまでの経験」と独自性素材シートから写す（「発信に出さない」経験は写さない）。本人が「話したくない」と飛ばした所は空欄のまま「本人の希望で未記入」と書き、ここで聞き直さない
- 本人の⑥は、01の「これから進みたい未来」があれば写す。無ければ空欄でよい（期限と理由を決めるのは concept-brush-up）
- 読み方：**同じ欄は需要の証拠、違う欄が自分の立ち位置。** ③④が同じでも、①②か⑤⑥が違えば並んで立てる。**6つとも同じなら、上手な人の劣化版になる**ので、①②か⑤⑥のどこかを本人の物に差し替える案を一緒に探す
- 本人の②が空で、STEP 0 で生い立ちの1問をまだ聞いていなければ、ここで1回だけ聞く（話せる範囲でよい・飛ばしてよい、を添える）。STEP 0 で聞いた・「本人の希望で未記入」なら聞かない
