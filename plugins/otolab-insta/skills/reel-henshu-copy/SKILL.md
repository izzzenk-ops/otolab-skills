# リール完コピ（完コピ用カード発行）スキル

参考リールのURLを渡すと、**そのリールと全く同じ秒数・同じカット割りでカードが発行される**。
各カードに自分の素材をはめるだけで、伸びているリールの編集リズムを完コピできる。

- **秒数の元** … アフレコ編集(reel-henshu-afreco)が「アフレコの喋りのタイミング」で秒数を決めるのに対し、こちらは **参考リールのカットの切り替わり（シーン検出）** で秒数を決める。
- **完コピする対象** … 尺・カット割りだけ。映像・音声・テロップは自分の素材を入れる（＝型の完コピ）。
- **お手本プレビュー** … 各カードの横で参考リールの該当カットを再生できるので、見比べながらハメられる。
- **秒数の微調整** … カードごとの秒数はエディタの数字入力で変更できる（変えると以降のカードが自動でずれる）。

このスキルは **reel-henshu-afreco（アフレコ編集）のエディタ・書き出しエンジンを流用**する。
入口（カードの秒数をどこから決めるか）だけが違い、編集画面・動画書き出しは共通。

> **⚠️ ローカルMacに触れる Claude Code 環境で実行すること**
> `~/reel-henshu-afreco` のローカルファイルを操作し、ffmpeg・yt-dlp をローカル実行する。
> ターミナルの `claude` コマンド、または Claudeデスクトップアプリの「Code」モードで動かすこと。
> ブラウザ版・Chat/Coworkモード・サンドボックス/クラウドセッションでは動かない。

## STEP 0：セットアップ確認（`~/reel-henshu-afreco` が無いとき）

このスキルは reel-henshu-afreco のエンジンに同居している。まず本体があるか確認する：

```bash
ls ~/reel-henshu-afreco/scripts/build_copy.py
```

- **存在する** → STEP 1 へ。
- **`build_copy.py` は無いが `build_shorts.py` はある** → reel-henshu-afreco は入っているがバージョンが古い。最新化して依存も入れ直す（yt-dlp 等が増えているため）：
  ```bash
  cd ~/reel-henshu-afreco && git pull && ./venv/bin/python3 -m pip install -r requirements.txt
  ```
- **`~/reel-henshu-afreco` ごと無い** → reel-henshu-afreco スキルの STEP 0（`git clone` ＋ `install.sh`）でまず本体を入れる。

### yt-dlp について

参考リールのURL取得に使う yt-dlp は **venv に自動で入る**（install.sh / requirements.txt に含む。build_copy.py が `python -m yt_dlp` で呼ぶ）。個別インストール（brew 等）は不要。
念のため確認するなら：

```bash
~/reel-henshu-afreco/venv/bin/python3 -m yt_dlp --version
```

（URLではなく手元の動画ファイルを参考にする場合は yt-dlp は使わない。）

## STEP 2：【必須】この編集に使う素材フォルダを必ず聞く

**URLを受け取ったら、次は必ずこの質問をする。飛ばさないこと。**
初めて使う人は「自分の素材フォルダを選ぶ」という発想がないままエディタに進み、
何をはめればいいか分からず詰まる。ここで先にフォルダを決めさせるのが肝。

必ず次のように聞く（プロジェクト名も一緒に）：

```
この編集に使う素材フォルダはどれですか？
（完コピの各カードに、このフォルダの中の動画・画像をはめていきます）

・素材フォルダのパス（mp4/mov/jpg/png/HEICが入ったフォルダ）
  例: /Users/you/Desktop/my_materials
・プロジェクト名（英数字・アンダースコア推奨。例: my_copy）
```

**フォルダのパスを受け取ったら、必ず存在と中身を確認する**：

```bash
ls "<素材フォルダ>"
```

- フォルダが無い / 動画・画像が1つも無い → **もう一度フォルダを聞き直す**（ここは徹底する）。
- 「まだ素材フォルダが無い」と言われたら → 先に素材を1つのフォルダにまとめてもらう。
  素材が用意できるまでは STEP 3 に進まない。

（`build_copy.py --materials` にこのフォルダを渡すと、発行と同時に素材を取り込むので、
エディタを開いた時点で各カードのプルダウンに素材が並ぶ＝すぐはめられる。）

## STEP 3：完コピ用カードを発行する

```bash
~/reel-henshu-afreco/venv/bin/python3 ~/reel-henshu-afreco/scripts/build_copy.py \
  "<参考リールURL または 動画パス>" \
  --project "<project>" \
  --materials "<素材フォルダ>"
```

（`--materials` は任意。省略時はエディタで後から取り込む。）

処理内容（ログで確認できる）：
1. 参考リールを取得（URLは yt-dlp。ローカル動画はコピー）
2. シーン検出でカットの切り替わり点を抽出
3. 参考と同じ秒数で各カット＝1カードを発行（全カード未割当て）

完了したら **カード数・合計秒数（＝参考リールと同じ尺）** をユーザーに報告する。

> **カットの拾い方を調整したいとき**（`--threshold` は scdetスコア0〜100。既定 5.0）
> - カットを拾いすぎ / 細かすぎる → `--threshold 8`（数字を上げると鈍感に）や `--min-dur 0.6`（短いカットを手前に吸収）
> - カットを拾えていない / 大まかすぎる → `--threshold 4`（数字を下げると敏感に）
> ※同じ構図のジャンプカット（固定カメラで具材を次々入れる料理リール等）は感度を下げても
>   拾えない。それはエディタの「✂️ 自動分割」でカードごとに分ける。
> 既定は `--threshold 5.0 --min-dur 0.4`。

---

## STEP 4：エディタを開いて素材をはめる

```bash
kill $(lsof -ti :8766) 2>/dev/null
~/reel-henshu-afreco/venv/bin/python3 ~/reel-henshu-afreco/scripts/editor_server.py <project> &
sleep 1
open http://localhost:8766
```

ユーザーに伝える：

```
エディタを http://localhost:8766 で開きました。

使い方（完コピの流れ）：
1. STEP 2で選んだフォルダの素材は取り込み済み。各カードのプルダウンから
   素材を選んではめていくだけ（後で素材を足したら「🔄 動画素材フォルダを更新」）
2. テロップ欄には参考リールのテロップ（ナレーション）が薄いグレーの見本で入っている。
   自分の言葉に書き換える前提（打ち込むと消える）。何も入れなければ焼き込まれない。
3.「▶ お手本」を押すと、そのカードのカットだけが左でループ再生される
   （次のシーンは映らないので、どこで区切るべきかが分かる）
4. お手本を見て「このカード、実は複数カット入ってる」と気づいたら「✂️ 自動分割」を押す。
   **何分割かは数えなくてよい**——そのカードの中に実際に何カットあるかをツールが判定し、
   参考リールの実際のカット位置に合わせて**不均等に**割る（例: 0.57/0.27/0.80秒）。
   合計の尺は変わらず、以降のカードもずれない。自動で分かれない/分けたい数が決まって
   いるときは、隣の「手動〔枚数〕分割」で枚数を指定できる。
   ※分割しすぎたら「🗑カード削除」で戻せる。削除した分の尺は隣のカードに足されるので、
     合計の尺（＝参考リールとの同期）は保たれ、以降のカードもずれない。
5. 各カードの「尺 ◯◯ 秒」の数字を変えると、そのカードの長さを微調整できます
   （変えると以降のカードも自動でずれます）
6.「今すぐ更新する」で通しプレビュー、「⬇ 動画出力」で書き出し
```

> **⚠️ お手本を見ながら「1カードに複数カットが入っていないか」を必ず確認する**
> 自動のカット検出（シーン検出）は、画面が大きく切り替わるハードカットは拾えるが、
> **同じ構図のジャンプカット**（例: 固定カメラで具材を次々入れる料理リール。カメラ位置が
> 同じで画がほぼ変わらない）は原理的に拾えず、実際は複数カットでも1カードにまとまる。
> これは感度(`--threshold`)を上げても全体が過剰分割されるだけで解決しない既知の限界。
> **お手本と見比べて、まとまってしまっているカードは「✂️ 自動分割」で分ける。**
> ツールがそのカードの参考区間内のカット数と境界を検出し、元リールと同じ不均等な尺に
> 自動で割る（ユーザーは枚数を数えたり秒数を手入力したりしなくてよい）。誤って刻みすぎない
> よう保守的に判定する（各カット最短0.25秒。足りなければ手動分割で足せる）。

## ファイル構成（このスキルが足すもの）

reel-henshu-afreco のエンジンに以下を追加している：

```
~/reel-henshu-afreco/
├── scripts/
│   └── build_copy.py        # ★このスキルのCLI（参考リール → 完コピ用カード）
├── editor/index.html        # エディタ（copy_mode時に「尺の数字入力」と「▶お手本」を表示）
└── work/<project>/
    ├── reference.mp4         # 取得した参考リール（お手本プレビューの元）
    ├── timeline.json         # copy_mode:true / 各カードに ref_in・ref_dur を保持
    ├── materials.json        # 自分の素材
    └── final.mp4             # 書き出し済み動画
```

## よくあるエラーと対処

| エラー | 原因 | 対処 |
|---|---|---|
| `No module named yt_dlp` | venvにyt-dlp未導入（古い環境をpullした等） | `~/reel-henshu-afreco/venv/bin/python3 -m pip install -r ~/reel-henshu-afreco/requirements.txt` |
| 参考リールの取得に失敗 | 非公開・ログイン必要 | build_copy.py は自動でChromeのcookieでも再試行する。ダメなら手元に動画を保存してそのパスを渡す |
| カットが細かすぎ / 粗すぎ | シーン検出の感度 | STEP 3 の `--threshold` / `--min-dur` を調整して再実行 |
| エディタが開かない | ポート8766使用中 | `kill $(lsof -ti :8766)` してから再起動 |
| `timeline.json が見つかりません` | build_copy.py 未実行 | 先に STEP 3 を実行 |
