# ジャンル引き出しリスト（STEP 1用）

候補ジャンル出しの引き出し。**これは引き出しであって答えではない。** 本人の自己分析・生活・経験から出てきた「種」と突き合わせて使う。リストにないジャンルももちろんOK。

使い方：
- ①ルート（売りたいものがない人）：自己分析の棚卸しと照らして「これならできるかも」を2〜3個拾う
- ②ルート（売りたいものが明確な人）：売りたいものの関連・届けたい相手が重なるジャンルを探す
- 各ジャンルの（　）はパイの目安と収益化の代表的な道。実際の需要は必ずSTEP 2で数字を取って確認する（このメモだけで判定しない）

## ②ルートの連想の広げ方（実例）

売りたいものから「届けたい相手が重なるジャンル」まで広げる思考の型：

- 売りたいもの＝ショート動画の教材
  - 直接関連：インスタ運用系・SNSマーケ系
  - 連想：ショート動画＝動画編集 → 動画編集がいけるなら動画撮影もいける → 撮影がいけるなら写真もいける → 「写真の撮り方」はやりたい人が非常に多い
  - 判定の実例：インスタ運用系は爆発的に再生が取れず競合過多→見送り。AI系は伸びるが本人が得意でなくリサーチが重い→「継続できる」の掟でNG。写真の撮り方はトップ層20万人超でパイが大きい→採用（実際に9投稿で2.1万人）
- 売りたいもの＝美肌講座
  - 直接関連：スキンケア系
  - 連想：肌がきれいに見える→メイク→垢抜け→痩せレシピ（食から美肌）
  - ずらし導線の実例：投稿は「痩せレシピ」でパイを取り、ストーリーズで垢抜け・スキンケアを発信→美肌講座へ
- 売りたいもの＝金融アフィ・お金の講座
  - 直接関連：節約・家計管理
  - 連想：節約→節約レシピ（食から入る）→ふるさと納税・ポイ活
  - ずらし導線の実例：投稿は「節約レシピ」、ストーリーズで家計管理・投資の基礎→金融アフィ（炊飯器レシピ×お金の価値観語りで脱サラした実例あり）

ポイント：**投稿で戦うジャンル（パイの広さ重視）と、収益化するジャンル（売りたいもの）は同じでなくていい。** ずらして繋ぐ設計はSTEP 3で行う。
