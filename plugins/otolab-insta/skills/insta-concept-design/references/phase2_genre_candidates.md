# Phase 2: 発信ジャンル候補10（旧「コンセプト3案」を2026-09-03に全面変更）

## このフェーズの役割

**決めない。選択肢を見せる。**

受講生に「自分にはこんな発信ができそう」というイメージを持ってもらうための、ジャンル候補カードを10枚作る。
ここでコンセプトを1つに決めることはしない。決めるのはずっと後（concept-brush-up の決定版）。

### なぜ変えたか（2026-09-03・運営者判断）

旧版はここで「仮コンセプト3案」を出していたが、次の工程でもう一度決め直すので**二重に決めさせる形**になっていた。
さらに3案は「処方箋」なので1つ外すと痛手が大きく、受講生から「的から外れている」という声が出ていた。
10枚のメニューにすれば、合わないカードは選ばれないだけで済む。**外れのコストが下がる。**

### 旧版からやめたこと（重要・戻さない）

- ❌ **最初に「発信ジャンルは何ですか？」と聞くのをやめた。** ジャンルが未定の人がここで適当に答えると、その上に積んだ提案が全部ズレる。ジャンルは Phase 1 の素材からこちらが候補を出す
- ❌ **コンセプト3案を出すのをやめた**（決めさせない）
- ❌ **届けたい相手の深掘り（「なぜそこに悩むのか」）をここでやるのをやめた。** concept-research の STEP 1 に同じ工程があり二重だった。深掘りはジャンルが決まってからの方が精度が出る
- ❌ **掛け算式・ギャップを要求するのをやめた。** 素材が薄い段階で埋めさせると捏造になる。あれは concept-brush-up の仕事
- ❌ **「ジャンル横断・フォーマット掛け合わせを必ず盛り込む」という創造性の指示をやめた。** 素材が薄いほど暴走して「面白いけど自分じゃない」案になる原因だった

## 進め方

### 1. 素材を読む（質問から始めない）

`01_自己分析レポート.md` を読む。とくに次の3つが10枚の原料になる：

- 「独自性素材シート」（特徴・ギャップ・エピソード）
- 「発信できそうなジャンルの種」
- 本人の発言の原文引用（生活・仕事・過去の悩み・人から相談されること）

素材が足りない場合だけ、**1問ずつ**追加ヒアリングする：

- 毎日・毎週、どうせやっていることは何ですか（家事・仕事・移動・趣味）
- 人からよく相談されることは何ですか
- 過去に自分が悩んで、抜け出した経験は何ですか
- 顔出しはできますか（顔NG／後ろ姿／手元だけ 等）

### 2. 10枚のカードを作る

`references/genre-85sen.md`（ジャンル引き出し・パイと収益化の目安つき）と
`references/concept-examples.md`（発信イメージの引き出し200例）の**両方**を読んでから作る。

- **genre-85sen.md** ＝ カードの「枠」（ジャンル名・パイ・収益化の道）
- **concept-examples.md** ＝ カードの「近い形の例」（この枠だとこんな見え方になる、の例示）

#### 10枚の配分（必ず守る）

| 枚数 | 中身 |
|---|---|
| 5枚以上 | **王道ジャンル**（genre-85sen.md の「パイが特に広い王道ゾーン」「美容・健康ゾーン」など）。奇をてらわない。タグは「王道」 |
| 2〜3枚 | この人の経験・立場・職業からしか出てこない**固有の枠**。タグは「独自」 |
| 1〜2枚 | 「あえて手間をかける少数派」寄りの枠（concept-examples.md の切り口）。タグは「すき間」 |

尖った案で10枚を埋めない。**受講生が最初に欲しいのは「普通にやれそうな道」の見取り図**で、尖りは後の工程（brush-up）で足す。

#### 1枚のカードに書くこと

```
【ジャンル名】発信イメージの一言　※ジャンル名に「継続実況：」のような型の名前を付けない
├ あなたのこの話から: 自己分析での本人の発言をそのまま引用（1行）
├ こんな発信になりそう: この枠で発信するとどう見えるか2〜3行（投稿1本が浮かぶ具体度）
├ 近い形の例: 引き出し集から近い例を2つ
└ パイ / 収益化の道 / 続けやすさ
```

#### 外さないための必須ルール（これが的外れ防止の本体）

1. **「あなたのこの話から」を書けないカードは出さない。** 自己分析での本人の発言・生活・経験に必ず紐づける。紐づけられないなら、そのカードは思いつきなので捨てる
2. **「続けやすさ」は生活導線で判定する。** 「どうせ毎日（毎週）やることのついでに撮れるか」。撮るためにわざわざ出かける必要がある枠は、その旨をカードに正直に書く
3. **フォロワー0の初日でも始められる枠にする。** 依頼者・お客さん・フォロワー参加が前提の枠は出さない。人を巻き込むなら友人・同僚・家族など手が届く相手で完結する形にする
4. **参考アカウントは出さない**（2026-07-10 運営者判断・継続）。AIのアカウント選定は精度が微妙で、間違った参考例を見せる害の方が大きい。「近い形の例」は引き出し集からの**形の例示**であって、実在アカウントの提示ではない
5. **専門用語を使わない。** パイ→「見ている人の数」、マネタイズ→「収益化」、ニッチ→「すき間」

### 3. HTMLで見せる

1. `assets/report_template.html` をベースにHTMLを作る。デザイン（配色・フォント・角丸）はテンプレートのまま変えない。カードは10枚、奇数は `class="concept"`・偶数は `class="concept alt"` で交互に並べる
2. `<対象者名>/02_ジャンル候補10.html` に保存し、`open <パス>` でブラウザで開いて見せる
   （Chrome拡張の navigate は file:// URL に非対応＝https を前置してしまうので使わない。2026-07-29実機確認）
3. 同じ内容を `<対象者名>/02_ジャンル候補10.md` にも保存する（genre-sentei が読みに来る）
4. **チャットには10枚のタイトル一覧だけ**を番号付きで書く。カードの中身をチャットに再掲しない

### 4. 締め方

- 「**気になるものを2〜3コ**教えてください。1つに絞らなくて大丈夫です」と伝える
- 「ここでは決めません。次にこの候補が本当に伸びているジャンルかを数字で調べて、そこで1つに決めます」と必ず伝える
- 選んでもらったら `02_ジャンル候補10.md` の末尾に「## 本人が選んだ候補」として記録し、`00_state.md` を更新する
- 次の案内：「この候補を市場の数字で確かめて1つに決めるなら **ジャンル選定（genre-sentei）** に進めます」

### 5. 選ばれなかった7枚も残す

`02_ジャンル候補10.md` には10枚すべてを残す。ジャンル変更を考えるときの資産になる。

## 言葉遣い（全フェーズ共通・上の指示より優先）

- 専門用語を出力に使わない
- 硬い敬語を使わない。「させていただきます」ではなく「していきますね」
- 数字の気配がある回答には「数字でいうと？」と追い質問する
- **1問ずつ聞く**
